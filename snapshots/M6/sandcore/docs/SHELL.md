# SandCore Shell 规范 v0.3（M2 沿革 + M6 SandShell）

> §1-4 是 M2 历史记录。当前实现为 `user/shell.asm`，见 §4.5；`kernel/shell.c` 不进入构建。shell 是内核里第一个"像应用"的东西：
> 行缓冲 → 分词 → 命令表分发，三段流水，60 行骨架。

## 1. 输入流水

```
getkey() ──> shell_feed(char k)
                │
   ┌────────────┼──────────────┐
   │可打印(32..126)│  '\n'        │  '\b'
   ▼            ▼              ▼
 行缓冲(≤63)+回显  提交执行+清缓冲  行内删除(缓冲空则静默忽略)
```

- 行缓冲 64 字节，满则丢弃后续字符（不响铃，v1 没有蜂鸣器驱动）；
- **退格守卫**：以 `llen`（缓冲长度）为准——缓冲空时退格是空气，
  提示符 `sandcore> ` 物理上删不掉（M1 验收反馈换来的纪律）；
- 控制字符 Esc/\t 等暂不入缓冲，M3 按需扩充。

## 2. 分词与调用约定

- 就地分词：空格改 `'\0'`，argv 指进行缓冲本体（零拷贝）；
- 上限 argv[8]，超出忽略；
- 命令匹配 = 精确匹配命令表 `name` 字段（大小写敏感）；
- 未命中 → 琥珀色 `unknown: xxx  (try 'help')`。

## 4. 提示符

`sandcore> `（米白），每次回车后重印。M2 的提示符还是装饰——M2.5 起它背后
站着真正的命令解析，M5 后它是用户态的入口。

## 4.5 M6 SandShell（ring3）

开机只有桌面，单击 Shell 文件图标才执行 `bin/shell.scx`。程序用 SYS_WINOPEN、PUTS、FILL、GETKEY、FSLIST、EXEC，内核没有 Shell 命令分发。
当前命令：help、clear、echo、ls、run、exit。完整命令边界匹配，空行直接印新提示符。
流式输出游标在本人窗口内，自动折行与滚动；退格以行长守卫，清除整格像素；clear 重置画布与游标。
`run apps/hello.scx` 异步启动私有页目录的新任务，Shell 保留自己的提示符与输入状态；子窗口取键不能偷走后台 Shell 的队列。
输入限 63 字符；文字游标支持折行退格，空行长度守卫仍保护提示符。按键 Enter 的 ASCII 为 LF=10。
未命中内建命令时把首词包装为 `bin/<命令>.scx`，其余参数传给新程序，例如 `asm home/demo.asm apps/demo.scx`。
`run` 同样支持参数，例如 `run apps/note.scx home/check.txt`。程序异步运行，创建自己的窗口，Shell 提示符不混入子窗口。
