# SandCore 系统调用 API v0.4（M6，作者 mio）

> **作者: mio** ｜ 沙核 OS 应用编程接口。用户程序 (ring3) 经软中断
> `int 0x7C` 调用内核服务（向量 0x7C 是沙核自己的选择，刻意区别于 Linux 的 0x80）。
> **本文是 ABI 权威**：寄存器约定以 `kernel/task.c` 的 `syscall_c_common()` 为准逐条核对过。

## 1. 调用约定

```
EAX = 功能号
参数寄存器（按各调用定义）: EBX / ECX / EDX / ESI / EDI / EBP
返回值放 EAX（成功多为 0 或正数/句柄；负数或 0xFFFFFFFF = 失败）
除 EAX 外寄存器不保证保留
```

- 系统调用门：IDT 向量 0x7C，attr = 0xEE（P=1, **DPL=3** —— 用户态可触发），32 位中断门
- 触发即陷入 ring0，CPU 自动切到当前任务内核栈（TSS.esp0，调度器每次切换时更新）
- 用户指针（字符串/缓冲）**必须落在本任务用户区 0x400000-0x7FFFFF**；
  系统调用沿用调用者 CR3，直接访问用户虚址。字符串最多检查 4096 字节；缓冲区逐页检查映射，非法指针返回 -1。
- 颜色参数一律是**调色板槽位号**（见 `kernel/palette.h` / docs/GFX.md §2），不是 RGB

## 2. 功能号全表（v0.4 现状）

### 进程与参数（0x00-0x05）

| 号 | 名称 | 入参 | 返回 | 说明 |
|---|---|---|---|---|
| 0x00 | SYS_EXIT | — | 不返回 | 回收本人全部窗口，置僵尸并立即调度；后续调度安全释放用户页、页表、内核栈 |
| 0x01 | SYS_PUTS | EBX=字符串(ASCIZ) | 0；-1 无窗口/非法指针 | 向本人最近创建的窗口追加文字。独立光标、自动折行/滚动，支持 LF/CR/BS；字色 PAL_TITLE |
| 0x02 | SYS_GETTICK | — | EAX=PIT tick | 开机心跳数（100Hz） |
| 0x05 | SYS_GETARGS | EBX=缓冲 EDX=容量 | 复制字节数；-1 非法缓冲 | 读取 EXEC 首个路径之后的参数串，最多 127B，最多复制容量-1 字节并保证 NUL；空参数返回 0 |

### 窗口与桌面（0x10-0x19）★ M6a/M6

| 号 | 名称 | 入参 | 返回 | 说明 |
|---|---|---|---|---|
| 0x10 | SYS_WINOPEN | EBX=标题 ECX=宽 EDX=高 | EAX=窗口句柄(≥0)，负=失败 | 开窗口（自动居中；上限 6 个，画布上限 304×150） |
| 0x11 | SYS_WINCLOSE | EBX=句柄 | 0 | 关闭本人窗口（校验 owner） |
| 0x12 | SYS_TXT | EBX=句柄 ECX=x EDX=y ESI=串 EDI=颜色 | 0；-1 非法指针 | 向本人窗口画布写透明底 8×8 ASCII，支持 LF，按客户区裁剪 |
| 0x13 | SYS_FILL | EBX=句柄 ECX=x EDX=y ESI=宽 EDI=高 EBP=颜色 | 0 | 向本人画布写实心矩形，整画布填充时重置流式文字光标 |
| 0x14 | SYS_GETKEY | — | EAX=ASCII 或 -1 | 仅调用者拥有聚焦窗口时取键；LF=10、BS=8、Esc=27；无键返回 -1，**不阻塞** |
| 0x15 | SYS_MOUSE | — | EAX = x \| y<<9 \| 按键<<18 | 鼠标状态打包（x,y 各 9 位，按键 bit0 左/bit1 右/bit2 中） |
| 0x18 | SYS_WALLPAPER | EBX=模式 | 0；-1 模式非法/保存失败 | 0 沙丘、1 夜色、2 暖沙；先写 sys/wall.cfg，再切换；重启恢复 |
| 0x19 | SYS_WININFO | EBX=句柄 ECX=缓冲(20B) | 0；-1 非本人窗口/非法缓冲 | 写五个 i32：外框 x/y、客户区 cw/ch、focused；将鼠标绝对坐标转为客户区时减 x+1/y+13 |

### 文件系统（0x30-0x32）★ M6a 新增

| 号 | 名称 | 入参 | 返回 | 说明 |
|---|---|---|---|---|
| 0x30 | SYS_FSREAD | EBX=路径 ECX=缓冲 EDX=上限 | 字节数，-1=没有 | 读整文件进用户缓冲 |
| 0x31 | SYS_FSWRITE | EBX=路径 ECX=数据 EDX=长度 | 写入字节数，-1=失败 | 写/新建文件（原地放得下则重写，否则追加数据末端；目录表自动写回） |
| 0x32 | SYS_FSLIST | EBX=缓冲 EDX=上限 | 生成字节数 | 列目录：每行 `路径 大小\n`，整体 NUL 结尾 |

### 进程启动（0x40）★ M6a 新增

| 号 | 名称 | 入参 | 返回 | 说明 |
|---|---|---|---|---|
| 0x40 | SYS_EXEC | EBX=命令串 `路径 参数` | EAX=pid(≥0)；-1 文件/路径/参数或任务槽失败，-2 魔数错，-3 尺寸/基址/入口/栈非法，-4 内存不足 | 路径至首个空格，≤31B；其余参数去前导空格并拷贝到子任务槽，≤127B。异步运行，分页后同程序可同时跑多份 |

## 3. 规划中的功能号（落地时登记进 §2）

```
0x03  SYS_PUTDEC      打印十进制数
0x16  SYS_EVENT       统一事件队列（窗口暴露/关闭/重绘请求）
0x17  SYS_ICON        从 SCX 内嵌图标字段读图标（M6 规划：图标信息写进可执行文件）
0x1A  SYS_WINMOVE     移动/改尺寸窗口（未实现；0x19 已分配 WININFO）
0x0100+ 内存：申请/释放用户页
0x0500+ 汇编器/编译器服务（M6b/M7：SCCC 依赖）
```

> 【窗口 API 说明】（mio 交代）内核侧窗口接口（wm_open_user_window 等）是 ring0
> 内部函数；对用户程序的一切能力都经本文件的 0x1x 号段暴露，新增能力先在此登记规格。

### 边界与事件细则

- WINOPEN 参数是外框尺寸；最小 48×32，上限 306×164，客户区从 `(1,13)` 开始，最大 304×150。
- 窗口句柄独立于 z 序；TXT/FILL/CLOSE 对非本人或已关闭句柄静默不操作，现有返回仍为 0。WININFO 返回 -1。
- GETKEY 有效队列容量 15，满丢新键。普通 ASCII、LF=10、BS=8、Esc=27；F2=2、F3=3、F5=5；方向键上/下/左/右=0x80/0x81/0x82/0x83。没有按键返回 -1。
- SYS_MOUSE 是全局位置与按钮快照；应用必须配合 WININFO.focused 判断，避免后台点击穿透。
- SYS_PUTS 不支持 ANSI 转义；ASCII 字宽 8px、行高 10px，自动折行/滚动、CR 回行首、BS 清整格并可回前一视觉行。输入提示符保护由 Shell 自己的行长守卫负责。
- FSLIST 生成完整文件行，容量不足时停止追加并保留 NUL；不分配用户缓冲。FSREAD 允许按容量截断，FSWRITE 只写实际长度，零字节文件合法。
- 数据盘固定 8MB，目录最多 96 项；错误返回 -1。SandFS 没有事务日志，IO 失败可能已经写入部分数据，不能把失败等同于完整回滚。
- 普通系统调用原路恢复；PIT 100Hz 负责抢占。EXIT 才在系统调用出口立即切走，避免每次绘字都等待下一时钟。

## 4. 用户程序的样子（user/hello.asm 节选，平二进制，零依赖）

```nasm
[bits 32]
[org 0x400000]              ; 所有程序统一装载基址（分页后各任务映射到私有物理帧）
_start:
    mov eax, 0x10           ; SYS_WINOPEN
    mov ebx, wtitle
    mov ecx, 220            ; 宽
    mov edx, 110            ; 高
    int 0x7C
    mov [win], eax          ; 句柄存好, 后续调用都要带
    ...
    mov eax, 0x00           ; SYS_EXIT
    int 0x7C
```

构建链：`nasm -f bin app.asm -o app.bin` → `python tools\mkscx.py app.bin app.scx`
→ 放进 `build/fs/` 对应目录 → `make` 自动上盘 → 系统里点图标或 `run 路径`。
