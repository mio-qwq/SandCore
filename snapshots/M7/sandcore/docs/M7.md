# M7：Welcome to Graphics（欢迎来到图形的世界）

> 作者 mio，2026-10-02。核心、编译器、图形工具、游戏、短片与字体均已取得
> Windows QEMU 行为证据；最终运行盘和 M6 联合回归也已通过。用户界面验收待确认。

## 1. 本次目标与顺序

1. 先扩充引导容量与用户程序容量，再实现三环异常隔离：未注册处理器的异常
   暂停对应任务并弹出诊断卡片，关闭卡片才杀掉任务；内核自身异常仍进入 panic。
2. 增加逐帧画布提交、输入状态、让出、调试与文件操作接口，形成稳定的用户态底座。
3. 实现原生 x86 C 编译器 SCCC，命令为 `s3c`；唯一公共头文件为 **`SCAPI.H`**，
   文件名完全大写。系统调用用内联汇编封装，宿主工具链只提供首次启动版本。
4. 实现可在任意位置编辑、保存、编译 C/汇编、显示错误、运行和调试的图形 IDE；
   图形调试器必须实际读取现场、设置断点、单步、继续与查看内存。
5. 文件管理器按完整路径中的 `/` 推导下一级目录；磁盘仍保存平铺的完整路径，
   增加空目录记录、规范化路径及创建/删除/重命名能力。
6. 赛车、原创简化沙盒、3D 动画演示全部作为普通三环程序，逐帧绘制。
   IDE、文件管理器、调试器也用同一套可自定义的软件图形能力构建界面。
7. 在沙核内编译 SCCC 自身，再用生成的编译器编译 M7 应用；记录源码、输出、
   编译诊断、运行截图及复现命令。同步 M6/M7 合并自测指南和验收包。

## 2. SCCC 语言合同（实现与测试必须逐项对齐）

这是面向 32 位 x86 的原生编译器，输出 SCX1MIO 可执行文件。基本整数 C 功能
必须包括：`char/short/int/long`、有符号/无符号、指针、多维数组、结构体/联合体、
枚举、typedef、全局/局部变量、常量初始化、函数原型与递归、函数指针、sizeof、
类型转换；算术/比较/逻辑/位运算、赋值及复合赋值、前后自增减、三目运算；
if/else、while/do/for、switch/case/default、break/continue/return。

预处理必须支持对象宏和函数宏、`#undef`、`#include`、条件编译
（`#if/#ifdef/#ifndef/#elif/#else/#endif`）、字符串化与标记拼接；
嵌套展开、注释与字符串边界要有测试。唯一 API 头文件为 `SCAPI.H`。
具体容量上限和不支持的扩展要在实现完成后写入专门编译器规范，并给出明确诊断；
不以静默误编译代替错误。内核及本次应用继续不依赖浮点或 libc。

## 3. 自举与图形验收标准

- 编译输出是可被现有加载器执行的机器码，不把解释器执行冒充原生编译。
- 系统内第一次重建的 SCCC 必须能继续编译自身与应用；同源码第二次重建进行
  文件比较，用来发现代码生成不稳定或仅宿主版本可用的问题。
- 游戏至少验证连续帧变化、实际输入、退出回收；沙盒另验证建造/破坏及存档恢复。
- 调试器验证断点停下、现场可读、单步改变 EIP、继续与退出，不能只画寄存器面板。
- 异常验证除零/非法指令/非法地址与已注册处理器；暂停期间桌面和其他任务继续运行，
  关闭卡片后目标资源完整回收。
- 所有验证使用 Windows 无头 QEMU，软盘引导盘与 IDE 数据盘同时挂载，并截图留证。

### 4.1 证据怎么读

图形测试由 HMP sendkey/QMP 鼠标驱动，没有向游戏/IDE 状态变量写入测试值。
只读断言从真实 SCCC .map 的 OBJECT 地址出发，逐级解析目标页表再读取物理页。
检查内容包括源码保存字节、编译日志/返回码、EIP 改变、实际体素数组及真实磁盘存档。
所有应用退出后检查物理页计数回到仅 Shell 的基线。完整命令先拍截图，再提交。

验收盘安装系统内编译的产物，宿主 ELF/.sym 只用于启动版与诊断。以后改源码并
重新 build.bat 时必须重做原生链及 publish_native.py，才可继续声明运行的是原生产物。
本次为 320×200、256 色软件图形；不宣称 GPU 加速、高清画面、完整 ISO C、中文
输入法或整机内核构建已经自举。语言和容量的准确边界见 C.md、FONT.md、GAMES.md。
