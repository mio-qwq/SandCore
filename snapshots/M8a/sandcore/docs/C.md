# SCCC：原生 C 编译与系统内自编译 v0.2

> 作者 mio。命令 `s3c`，公共头文件 **SCAPI.H**。18 组原生语言测试、四组失败诊断
> 和 G1→G2→G3 收敛均已通过；七个 M7 应用由 G2 生成并实际运行。

## 1. 编译链

`s3c 源文件 输出.scx`：读取 SandFS 文件、展开宏/包含文件、建立类型与语法树、
生成 32 位 x86 机器码、解决函数/全局地址、封装 SCX1MIO。整个过程在 ring3
运行，不调用宿主编译器。诊断保存到输出文件名追加 `.log`（路径过长则 HOME/S3C.LOG）。
符号与源码位置另存 `.map`，用于图形调试器关联函数。没有 libc/浮点依赖。

编译器源码分为 s3c.c 和几个内部 `.inc`，它们是同一编译单元的源片段；
公共应用接口只有 SCAPI.H。首次用 WSL GCC 构建启动版本；随后在系统内
从 SYS/SRC 源码编译第一代与第二代 SCCC，比较输出，再编译 M7 应用。

## M8 第二阶段后端常数运算优化（2026-10-04，限定范围通过）

右侧无副作用整数字面量时，标量加减/乘/位运算/移位使用x86立即数，
省去右侧装载及表达式栈往返。正二次幂无符号除余使用逻辑移位/掩码；
有符号除法先按符号加divisor-1偏置再算术右移，保持C向零截断。
余数为原值减商乘除数，负值及INT_MIN仍精确。左侧实际求值一次，
调用/volatile/自增副作用保留；指针算术、零/负/非二次幂除数走原后端。
除零与INT_MIN/-1仍原异常路径，不在编译期消掉它们。

### 不使用的callee保存寄存器（2026-10-04）

原栈帧。因此没有N_ASM的函数省去EBX/ESI/EDI三对PUSH/POP；原值
从未修改，cdecl保留合同不变。含任意N_ASM时保守保存全部三个，
包含模板显式寄存器和clobber，不能只看输出约束。每函数解析前
node_count归1，只扫描本函数语法树；调用和递归的callee各自守约。
未来寄存器分配若使用这些寄存器，必须同步建立使用掩码，不能
把“无asm”永久当作“不使用”。不改变SCX布局、语言或SCAPI ABI。
