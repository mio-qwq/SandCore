# SandCore 系统调用 API v0.8（M8 实施中，作者 mio）

> **作者: mio** ｜ 沙核 OS 应用编程接口。用户程序 (ring3) 经软中断
> `int 0x7C` 调用内核服务（向量 0x7C 是沙核自己的选择，刻意区别于 Linux 的 0x80）。
> **本文是 ABI 权威**：寄存器约定以 `kernel/task.c` 的 `syscall_c_common()` 为准逐条核对过。
> 2026-10-03第一阶段新增图片代理0x7C..0x80：源码已接线，尚未构建/运行。
> 向量`int 0x7C`与EAX功能号0x7C是两个独立层级；不得混淆。

## 1. 调用约定

```
EAX = 功能号
参数寄存器（按各调用定义）: EBX / ECX / EDX / ESI / EDI / EBP
返回值放 EAX（成功多为 0 或正数/句柄；负数或 0xFFFFFFFF = 失败）
除 EAX 外寄存器不保证保留
```

### M8 原生界面扩展（实现已接线，完整行为验收仍在推进）

旧功能号/SCX头不变；FRAME上限扩大，但必须精确匹配本人当前客户区。
旧窗口保持逻辑画布并整数放大，WININFO/MOUSE在高分辨率返回兼容虚拟
坐标，旧程序照旧减1/13。原生窗口必须用POINTER，不能靠9位打包读1080p。

| 号 | 名称 | 入参 | 返回/合同 |
|---|---|---|---|
| 0x20 | DISPLAYINFO | EBX=32B输出 | 0；宽/高/缩放/后端/代数/模式位图/预览秒/最大宽，均u32 |
| 0x21 | DISPLAYAPPLY | EBX=宽 ECX=高 EDX=百分比 ESI=action | 0成功，-1参数/设备，-2内存，-3保存；0预览15秒，1保存当前，2取消回退 |
| 0x22 | POINTER | EBX=窗口 ECX=24B输出 | 0/-1；6个i32为客户区x/y、当前按钮、按下沿、释放沿、聚焦；沿读后清零 |
| 0x23 | WINOPEN2 | EBX=标题 ECX=外宽 EDX=外高 | 句柄/负失败；物理像素、动态画布，屏幕工作区裁尺寸 |
| 0x24 | DESKTOPRELOAD | 无 | 0/-1；菜单整体验证后替换，坏配置保留上次有效菜单；快捷方式另刷新 |
| 0x25 | WINCONTROL | EBX=句柄 ECX=命令 | 0/-1；仅owner可用，0最小化、1最大化、2恢复/置顶 |
| 0x26 | MONITOR | EBX=192B输出 | 0/-1；只读统计快照，下述固定布局 |
| 0x27 | PALETTEINFO | EBX=1024B输出 | 0/-1；256个u32 0x00RRGGBB，未登记槽为0；不可借此改色 |
| 0x38 | FSREADAT | EBX=路径 ECX=输出 EDX=容量 ESI=字节偏移 | 实际字节数；EOF=0，越过EOF/路径/映射/IO失败=-1，不补NUL |

显示模式位图bit0..5依次320×200、640×480、800×600、1024×768、
1280×720、1920×1080。backend=0为13h，1为标准VGA DISPI 32bpp LFB。
scale仅100/150/200。确认/取消忽略宽高缩放，预览超时由内核执行，应用
退出/最小化不会取消安全回退。原生客户区宽=外宽-2，高=外高-标题高-1；
高分辨率标题高=24×scale/100，13h仍为13。程序每帧先查WININFO。

MONITOR前8个u32：接口版本1、PIT tick、管理内存B、已用B、空闲B、
任务槽数8、文件目录项数、可运行数；随后8行，每行pid u32/state u32/
name[12]。名称副本不保证12B内NUL，调用者另留第13B终止。任务状态
0空/1可运行/2僵尸/3暂停。没有CPU利用率、任务内存归属或任意任务写权限。

2026-10-02：M8追加0x20..27/0x38、原生FRAME尺寸与兼容坐标，完整验收见M8.md。

- 系统调用门：IDT 向量 0x7C，attr = 0xEE（P=1, **DPL=3** —— 用户态可触发），32 位中断门
- 触发即陷入 ring0，CPU 自动切到当前任务内核栈（TSS.esp0，调度器每次切换时更新）
- 用户指针（字符串/缓冲）**必须落在本任务用户区 0x400000-0x7FFFFF**；
  兼容代码区不变，M8另允许本任务私有图形堆0x40000000..0x43FFFFFF；中间区域不合法。
  系统调用沿用调用者 CR3，直接访问用户虚址。字符串最多检查 4096 字节；缓冲区逐页检查映射，非法指针返回 -1。
- 旧颜色参数为**调色板槽位号**；M8显式RGB接口接收0x00RRGGBB，不能混用两种画布的FRAME。

## 3. 规划中的功能号（落地时登记进 §2）

```
0x03  SYS_PUTDEC      打印十进制数
```

> 内部函数；对用户程序的一切能力都经本文件的 0x1x 号段暴露，新增能力先在此登记规格。

### 边界与事件细则

- WINOPEN 参数是外框尺寸；最小 48×32，上限 320×184，客户区从 `(1,13)` 开始，最大 318×170；旧 306×164 请求仍有 304×150 客户区。
- 窗口句柄独立于 z 序；TXT/FILL/CLOSE 对非本人或已关闭句柄静默不操作，现有返回仍为 0。WININFO 返回 -1。
- GETKEY 有效队列容量 15，满丢新键。普通 ASCII、LF=10、BS=8、Esc=27；F1..F7=1..7，F8/F9/F10=0x88/0x89/0x8A；方向键上/下/左/右=0x80/0x81/0x82/0x83。没有按键返回 -1。
- SYS_MOUSE 是全局位置与按钮快照；应用必须配合 WININFO.focused 判断，避免后台点击穿透。
- SYS_PUTS 不支持 ANSI 转义；ASCII 字宽 8px、行高 10px，自动折行/滚动、CR 回行首、BS 清整格并可回前一视觉行。输入提示符保护由 Shell 自己的行长守卫负责。
- FSLIST 生成完整文件行，容量不足时停止追加并保留 NUL；不分配用户缓冲。FSREAD 允许按容量截断，FSWRITE 只写实际长度，零字节文件合法。
- 数据盘发布64MB，旧8MB仍兼容；新v4目录512项/旧32扇区192项，路径
  63B；一般错误-1、核心保护-5。无事务日志，IO失败可能已经部分写入。
- 普通系统调用原路恢复；PIT 100Hz 负责抢占。EXIT 才在系统调用出口立即切走，避免每次绘字都等待下一时钟。

M8整帧复制的内部执行方式：FRAME/FRAME32完整校验后，在可信内核
持有当前任务/CR3的条件下STI复制，结束CLI解除持有。驱动能收IRQ，
其它任务/主循环仍看不到半帧，也不能关闭/resize目标或释放用户
源页；调用返回前完成整帧、alpha/dirty发布。功能号、被忽略寄存器、
长度、返回/错误及画布布局保持原合同，未新增用户禁抢占权。

## 4. 用户程序的样子（user/hello.asm 节选，平二进制，零依赖）

```nasm
[bits 32]
[org 0x400000]              ; 所有程序统一装载基址（分页后各任务映射到私有物理帧）
_start:
    mov eax, 0x10           ; SYS_WINOPEN
    mov ebx, wtitle
    mov ecx, 220            ; 宽
    mov edx, 110            ; 高
    int 0x7C
    mov [win], eax          ; 句柄存好, 后续调用都要带
    ...
    mov eax, 0x00           ; SYS_EXIT
    int 0x7C
```

构建链：`nasm -f bin app.asm -o app.bin` → `python tools\mkscx.py app.bin app.scx`
→ 放进 `build/fs/` 对应目录 → `make` 自动上盘 → 系统里点图标或 `run 路径`。
