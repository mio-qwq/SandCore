// ------------------------------------------------------------
//  全系统唯一的 16×16 汉字点阵定义处。每字固定为 16 行 × 16 列。
//
//  【沙核 OS 统一字体策略】
//   * 从本版本起，沙核 OS 全系统统一使用「凤凰点阵体 / Vonwaon Bitmap」。
//   * 当前 SCF-16 直接使用凤凰点阵体的原生 16px 字形，不做缩放。
//   * 以后新增汉字、补字、UI 文本或其他字号时，均应继续使用同一字体来源；
//     不再混用 GB19966、文泉驿、GNU Unifont、HZK 或其他中文字形。
//   * 若未来新增不同字号，应优先使用凤凰点阵体官方提供的对应版本；
//     如必须缩放/栅格化，也必须从凤凰点阵体生成，以保持全系统风格统一。
//
//  【字体来源】
//   * 字体中文名：凤凰点阵体 16px
//   * 字体英文名：Vonwaon Bitmap 16px
//   * 作者 / 发布者：Haoyu Qiu (Timothy Qiu)
//   * 字体版本：1.02
//   * 官方发布 / 更新页：https://timothyqiu.itch.io/vonwaon-bitmap
//   * 许可证：Creative Commons Zero v1.0 Universal (CC0 1.0)
//   * 许可证原文：https://creativecommons.org/publicdomain/zero/1.0/
//   * 官方压缩包内 license.txt 明确说明：允许个人、教育与商业项目使用；
//     支持署名 Haoyu Qiu，但署名不是强制要求。
//   * 开发机字体归档：C:\Users\Administrator\Desktop\projectos\vonwaon-bitmap.ttf.zip
//   * 本文件提取源：VonwaonBitmap-16px.ttf（压缩包中的原生 16px 版本）
//
//  【本文件生成方式】
//   * 使用字体文件以 16 px / 16×16 单元直接栅格化每个汉字。
//   * 该字体在 16 px 下输出的点阵为纯黑白像素（0/255），无需抗锯齿阈值处理。
//   * 每个像素转换为文本点阵：'#' = 墨（亮），'.' = 纸（暗）。
//   * 因此这里不是手工重画，也不是从更大字号缩小，而是直接提取原生 16px 字形。
//
//  【格式规则】
//   * 一行 "// 字 X" 开始一个新字（X = 要定义的汉字）。
//   * 紧跟 16 行点阵：'#' = 墨（亮），'.' 或空格 = 纸（暗）。
//   * 每字必须正好 16 行；每行必须为 16 列。
//   * "//" 开头的行是注释；空行可自由添加。
//
//  【修改后预览】
//   1) python tools\font_preview.py
//   2) 打开 build\font_preview.png 检查全部字形
//   3) mingw32-make  →  run.bat
//
//  【注意】请使用 UTF-8 编码保存。
