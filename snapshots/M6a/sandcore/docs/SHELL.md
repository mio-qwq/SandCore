# SandCore Shell 规范 v0.1（M2）

> 对应实现：`kernel/shell.c`。shell 是内核里第一个"像应用"的东西：
> 行缓冲 → 分词 → 命令表分发，三段流水，60 行骨架。

## 1. 输入流水

```
getkey() ──> shell_feed(char k)
                │
   ┌────────────┼──────────────┐
   │可打印(32..126)│  '\n'        │  '\b'
   ▼            ▼              ▼
 行缓冲(≤63)+回显  提交执行+清缓冲  行内删除(缓冲空则静默忽略)
```

- 行缓冲 64 字节，满则丢弃后续字符（不响铃，v1 没有蜂鸣器驱动）；
- **退格守卫**：以 `llen`（缓冲长度）为准——缓冲空时退格是空气，
  提示符 `sandcore> ` 物理上删不掉（M1 验收反馈换来的纪律）；
- 控制字符 Esc/\t 等暂不入缓冲，M3 按需扩充。

## 2. 分词与调用约定

- 就地分词：空格改 `'\0'`，argv 指进行缓冲本体（零拷贝）；
- 上限 argv[8]，超出忽略；
- 命令匹配 = 精确匹配命令表 `name` 字段（大小写敏感）；
- 未命中 → 琥珀色 `unknown: xxx  (try 'help')`。

## 3. 命令表（v0.3）

| 命令 | 功能 | 备注 |
|---|---|---|
| help | 命令列表 | 青色标题 |
| about | 版本宣言 | |
| mem | E820 + PF 分配器 + SC-Heap 统计 | docs/MEM.md 的运行时投影 |
| uptime | 开机秒数 + tick 数 | 二者互为 PIT 校验 |
| echo X… | 原样回显参数 | |
| clear | 清屏 | 复用 console_init |
| dune | 重画沙漠开机画面 | 按任意键返回，console 重建 |
| panic | 人为触发红屏 | 验证 panic 通路用，**会停机** |
| reboot | 8042 控制器脉冲复位（端口 0x64←0xFE） | |
| halt | cli + hlt | 只能断电/QEMU 退出 |

**中文命令名**：等 M3 的 SCF-16 中文点阵字体落地后接入——命令表结构已预留
每行一个别名字段，届时 `帮助/帮助` 双语并存，console 输出才能真正显示中文。

## 4. 提示符

`sandcore> `（米白），每次回车后重印。M2 的提示符还是装饰——M2.5 起它背后
站着真正的命令解析，M5 后它是用户态的入口。
