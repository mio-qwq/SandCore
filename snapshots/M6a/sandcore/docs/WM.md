# SandCore 窗口系统规范 v1.1（M4 + M6a 草案）

> 对应实现：`kernel/wm.c`（合成器）、`kernel/mouse.c`（鼠标驱动）、
> `kernel/term.c`（终端缓冲）。M4 是"内容与呈现分离"的里程碑：
> shell 输出进网格缓冲，窗口合成器负责把它画到屏幕的任何位置。

## 1. PS/2 鼠标驱动（IRQ12）

| 项 | 值 |
|---|---|
| 控制器 | 8042，数据 0x60，状态/命令 0x64 |
| 初始化四步 | `0xA8` 开辅助口 → 改配置字节（bit1 放行鼠标中断、bit5 恢复时钟）→ 经 `0xD4` 对鼠标发 `F6`（默认值）→ `F4`（开始上报） |
| 数据包 | 3 字节：B0 = 按键(bit0/1/2)+同步位(bit3 恒 1)+符号位(bit4 X / bit5 Y)；B1 = X 位移；B2 = Y 位移 |
| 同步 | B0 的 bit3 ≠ 1 → 字节流错位，整字节丢弃重对齐 |
| 溢出 | B0 的 bit6/7 置位时该帧作废 |
| 坐标 | `mx += dx`；`my -= dy`（PS/2 的 Y 正方向是向上，屏幕 y 向下，取反） |
| 限位 | 光标恒在 0..319 / 0..199 |
| ACK 处理 | 初始化期间鼠标会回 0xFA，用 suppress 标志压掉，结束再排水 |

IRQ12 在从片 (bit4)，初始化时放开；EOI 由 `irq_c_common` 统一发（主从各一次）。

## 2. 终端缓冲（term.c）—— 内容与呈现分离

- 网格 38 列 × 20 行，每格 = 字符 + 独立前景色；
- `shell → term_*` 写网格；`wm_compose` 读网格画进终端窗口客户区；
- 窗口拖动时终端内容**零重绘成本**（合成器直接读网格）；
- 退格语义：网格制下就是"清掉前一格"，`llen` 守卫仍在 shell 层。

## 3. 窗口与 z 序

```c
typedef struct { i32 x, y, w, h; const char *title; int type; } win_t;
static win_t wins[WMAX];   /* 数组顺序 = z 序: 0 最底, nwins-1 最顶(聚焦) */
```

- `win_create` 追加到末尾（= 置顶）；`win_raise` 点击置顶；`win_close` 收缩数组；
- 窗口外框含 1px 边框 + 13px 标题栏；聚焦窗口边框/标题用青色，未聚焦用灰；
- 类型：`WIN_TERM`（渲染终端网格 + 闪烁光标）/ `WIN_ABOUT`（静态中文页）。

## 4. 合成流水（wm_compose）

```
scene_paint()      壁纸: 沙漠落日 (main.c, 只画不上屏)
→ 各窗口按 z 序     边框/标题栏/关闭钮/客户区内容
→ 任务栏            底部 16px: 沙核(中文) + UP <秒>S 时钟
→ 鼠标光标          箭头精灵 (白身黑边, 画在最上)
→ gfx_swap()       垂直回扫整块上屏
```

- **脏标记模型**：鼠标移动/键盘输入/秒跳 → `wm_request_compose()`，
  主循环统一 `wm_compose()`。无脏矩形——全帧重绘在 QEMU 里毫秒级，
  脏矩形优化留给将来。
- 关闭钮：标题栏右侧 10×10 红块 + 白色 ×，左键点按即关。

## 5. 已知取舍（M4 刻意为之）

- 全帧重绘而非脏矩形（先对后快）；
- 鼠标状态读取无锁——单 CPU + 中断只在两条指令间插入，撕裂概率可忽略；
- 窗口数量上限 6（WMAX）；无最小尺寸/无窗口最大化；
- 中键/滚轮未用（PS/2 四字节包是 M6 的事）。

## 6. v2 画布模型（M6a，进行中 —— 细节以代码为准 + HANDOFF.md §3）

M6a 起窗口成为**系统调用资源**（SYSCALL.md §2 的 0x10-0x15 号段）：

- `win_t` 增加 `owner`（创建者 pid）与 `canvas`（客户区像素缓冲，304×150 上限，
  静态池 `canvas_pool[6]`）；合成器 blit 画布上屏；
- 键盘路由：keyboard ISR → `wm_key_input()` → **聚焦（最顶）窗口**的 16 深度按键队列，
  应用经 SYS_GETKEY 取；
- 桌面图标：`desk/*.lnk` 三行文本（显示名/目标 SCX 路径/图标 SCF 路径）+
  SCF1MIO 图标文件，`icn_draw()` 画字形 0；单击图标 → `task_exec_scx(目标)`；
- 【已知待修】SYS_TXT/SYS_FILL 目前画进后台缓冲会被画布 blit 覆盖 —— 需改为写
  `win->canvas`；任务退出后窗口未按 owner 回收。两条修法见根目录 HANDOFF.md §3.5/3.7。
