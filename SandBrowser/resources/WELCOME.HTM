welcome to the World Wide Web !

The Web is a collection of documents, ideas and links. Enter an address, follow a link, or open a page you have saved.

SandBrowser brings a familiar late-1990s desktop interface to SandCore: classic menus, navigation buttons, explorer bars and a detailed status line.

Built by mio, with credited open-source components.

Make yourself at home
  1. Type a complete address in the Address bar.
  2. Use Favorites to keep useful pages.
  3. Choose Go > Internet Options to set your home page.

About this first build

HTML and CSS are laid out with litehtml and Gumbo. JavaScript uses Duktape with a deliberately limited DOM bridge. HTTPS uses BearSSL with RDRAND/RDSEED entropy. Missing or incorrect UTC time is synchronized with time servers. The View menu and status bar adjust page zoom from 50% to 200%.

See the guide for the exact limits. This browser does not claim complete IE5 or modern Web compatibility.
