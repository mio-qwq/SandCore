Navigation

Type an HTTP or HTTPS address. If a scheme is omitted, HTTPS is assumed. File > Open also accepts an absolute local path or file:/HOME/FILE.HTM. Back and Forward use the current window's history. Each new window has separate worker processes.

Favorites, history and options

Favorites and History are explorer bars. Add favorites with a name, select one to open it, and use Favorites > Remove selected favorite to remove the selected item. The profile holds up to 64 favorites and 128 history entries. Go > Internet Options edits the home page and JavaScript preference. Reload a page after changing the script option.

Preferences are stored beside the installed application in FAVS.TXT, HISTORY.TXT and OPTIONS.TXT. An upgrade preserves these files and keeps the previous installation in the .OLD folder.

Pages and scripts

The HTML/CSS layout library supports blocks, inline text, lists, floats, positioning, tables, media queries and flex layout. The platform decoder supplies PNG, JPEG, WebP and BMP images; stb_image supplies the first frame of GIF images. One system font family is used with actual per-size rasterization. UTF-8 documents are the primary text format.

Duktape supplies variables, expressions, loops, functions, objects, arrays, JSON and regular expressions. The browser bridge provides getElementById, querySelector(All), getElementsByTagName/ClassName, createElement/TextNode, attributes, textContent/innerText/innerHTML, basic style assignment, appendChild/removeChild, values, checked state, focus, click/load/input/change/submit handlers, alert, console messages, timers and navigation. The event bridge has one listener slot per element/event. Advanced event propagation and Web APIs are incomplete.

Text fields, password fields, text areas, check boxes, radio buttons, buttons and select controls support basic interaction. Click a select to advance through its options. Tab moves between controls. Editing is deliberately basic; a full native text selection/IME widget is still pending. Forms submit URL-encoded GET or POST data; file upload and multipart forms are unsupported.

Network and HTTPS

The network library handles IPv4 DNS/TCP, HTTP/1.1, redirects, Content-Length, chunked transfer, gzip and zlib deflate. HTTPS uses TLS 1.2 with SNI and checks certificate signatures, hostname and UTC validity. It requires RDRAND and a valid UTC clock (2020-2099). Certificate errors cannot be overridden. HTTPS pages block HTTP subresources and redirect downgrades.

The trust store contains 53 unconstrained supported roots from a pinned Chromium snapshot. Roots whose extra policy restrictions cannot be represented are omitted. This is not Chrome's full trust policy. No online revocation, TLS 1.3, IPv6, proxy, HTTP/2, WebSocket or persistent disk cache is provided.

Cookies are session-only, exact-host and path restricted. Parent-domain cookies are rejected; cross-subdomain sign-in may not work. Cookie expiry/SameSite behavior is not a full modern implementation.

Limits and unfinished IE features

This is an initial native build, not a complete IE5 clone. Frames/iframes, SVG, animated GIF playback, CSS grid, downloadable fonts, text selection in page content, context menus, address autocomplete, printing, complete offline page saving, download management, plug-ins and ActiveX/VBScript are not implemented. Modern application frameworks, fetch/XHR, canvas, multimedia and a complete standards DOM are outside this build.

Network responses are capped at 16 MiB each, HTML at 4 MiB, page resources at 96 entries, and the JS heap at 8 MiB. Form submission is capped at 32 KiB. Rendering is limited to a 1920 by 1080 viewport. A failed worker is reported; reopen the browser to restart it.

Source and saving

View > Page source opens an escaped source document. File > Save source as writes the original HTML response to a path you choose. It does not package linked images, CSS or scripts. The browser asks before replacing an existing file.
