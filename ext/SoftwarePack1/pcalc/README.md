# PCalc —— 表达式 / 程序员计算器

## 用法
- 直接键入表达式，Enter 求值；Esc 先清错误行、再按才退出。
- 变量：`x=5` 赋值后参与后续表达式；`ANS` 自动保存上次结果。
- 函数：`ABS MIN MAX SQRT GCD LCM POW ROL ROR`（键帽自动带括号）。
- 字面量：`0x1F` `0b1010` `0o17` `'A'`；结果同屏 DEC/HEX/OCT/BIN。
- 历史环 16 条，点击任意一行回填输入框。
- F1 切换屏幕键盘；宽窗口显示 40 键，窄窗口使用五列；空间不足自动收起。

## 语义
整数即位模式：`+ - *` 回绕不算错；除零、`INT_MIN/-1`、移位越界
报错并在输入下画出错误字节定位符。未知变量/函数报错，不当 0。

## 配置（HOME/PCALX.CFG，安装器可写默认值）
- `keypad=1|0` 屏幕键盘初始开关。
