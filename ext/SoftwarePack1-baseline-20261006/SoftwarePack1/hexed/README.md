# SandHex —— 十六进制编辑器

## 视图
偏移（8 位 HEX）+ 16 字节 HEX 列 + ASCII 栏；0x00 字节弱化显示；
选中字节整格高亮（HEX 与 ASCII 同步）。

## 输入模式（F1 切换）
- HEX 模式：键入十六进制位逐半字节改写（高 4 位实时预览，凑满
  1 字节自动前进）；G/F/U/I 命令键只在 HEX 模式生效。
- TEXT 模式：键入可打印 ASCII 直接覆写当前字节并前进。

## 编辑安全
- 双栈撤销/重做各 65536 笔（U/I 或 Undo/Redo 按钮）；新编辑使
  重做分支失效（标准语义）。
- F6 还原到磁盘版本（有确认）；脏标记 `*` 显示在标题。
- 整文件读入 → 原地改写 → 整文件写回，与 SandFS 全量写语义一致；
  不支持插入/截断（是编辑器职责边界，不是缺陷）。

## 命令
| 键/按钮 | 功能 |
|---|---|
| G | 跳转偏移（`0x` 前缀可选，越界钳到末字节） |
| F | 搜索：自动识别文本/HEX 字节串（`0x` 前缀强制 HEX，`AB CD` 空格分隔偶数位也算 HEX）；从光标下一字节循环查找 |
| F3/F4 | 保存 / 另存为 |
| F5 / F7 | 打开 / 新建 256B 零缓冲 |
| F8/F9 | 视口翻页 |

## 配置（HOME/HEXED.CFG）
- `limit_mb=1..16` 可打开文件上限（默认 8MB）。上限是 freestanding
  环境的堆保护，不是格式限制。
