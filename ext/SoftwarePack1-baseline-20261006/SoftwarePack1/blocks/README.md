# SandBlocks —— 方块游戏

## 玩法
10×20 场地，7-bag 随机器（洗整袋，无长旱）。旋转带踢墙
（0/-1/+1/-2/+2 横移）；贴底 5 tick 锁定延迟（可微调）；Hold 每
次落子一次；Next 队列 3；幽灵落点（可配置）。

## 计分
| 动作 | 分 |
|---|---|
| 消 1/2/3/4 行 | 100/300/500/800 × 等级 |
| 软降 | 1 分/格 |
| 硬降 | 2 分/格 |

每 10 行升一级，下落间隔 30 tick 起按级递减（下限 4 tick）。
仿真固定 100Hz tick 步长：长帧不加速，速度与显示解耦。

## 按键
| 键 | 功能 |
|---|---|
| ← → / ↓ | 移动 / 软降 |
| ↑ / Z | 顺时针 / 逆时针旋转 |
| 空格 | 硬降 |
| C | Hold |
| P / R | 暂停 / 重开 |

## 持久化
- 前五成绩榜 `HOME/BLOCKS.SCORE`（score lines level name 文本行）；
  结束时进榜需录入名字（≤11 字符，Enter 确认）。

## 配置（HOME/BLOCKS.CFG）
- `startlevel=1..10`、`ghost=1|0`、`sound=1|0`（无声卡自动无效）。

## 音效
exaudio 程序化合成：锁定闷响、消行提示、Tetris 双音、Game Over
低鸣。全部整数包络合成，见 libex/LIBEX.md §3。
