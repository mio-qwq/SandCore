# SandSheet —— 表格计算器

## 网格
26 列（A..Z）× 128 行。单元格三种：公式（`=` 开头）、数字、文本。
数字右对齐、文本左对齐、错误高亮 `#ERR`；公式在公式栏可见原文。

## 公式
- 运算：`+ - * / ^`、一元负号、括号；double 精度。
- 引用：`A1`、`=B2*C3+1`；区间聚合：`SUM/AVG/MIN/MAX/COUNT(A1:B9)`。
- 标量函数：`ABS SQRT`。
- 循环引用检测：`A1=B1`、`B1=A1` 判 `#ERR`，不死循环。
- 除零/未知函数/坏引用/负数开方 → `#ERR`。

## 编辑与导航
- 方向键移动；直接键入=覆盖式输入；Enter 提交下移、Tab 提交右移。
- F2 编辑当前格原文；Del/Clear 清格；公式栏光标闪烁。
- F6 复制 / F7 粘贴当前格；F8 在当前行上方插行 / F9 删除当前行
  （整表平移，尾部溢出丢弃——有限网格的明确语义）。
- PgUp/PgDn 翻页（F9/F10 不占用，翻页走屏幕按钮或 Ctrl 组合外的
  PgUp/PgDn 按钮）。
- 鼠标：点击选格；底部 PgUp/PgDn/PgLf/PgRt 滚动按钮。

## 文件（CSV 往返）
- F3 保存 / F4 打开 / F5 另存为（路径对话框，目录可逐层浏览）。
- 保存的是**原文**（公式以 `=...` 保存），CSV 往返无损；RFC4180
  引号规则。超过 128 行/26 列的内容丢弃并在状态栏说明，不静默。

## 配置（HOME/SHEETX.CFG）
- `decimals=0..6` 数值显示小数位（四舍五入去尾零）。
- `gridlines=1|0` 网格线。
