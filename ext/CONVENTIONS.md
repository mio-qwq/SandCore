# ext 扩展生态工作约定（持久化，防遗忘）

> 2026-10-06 由 SandCore_ExtraSoftware_Pack_1 项目确立。后续任何
> ext 内的开发（含 SoftwarePack2）先读这里。

## 1. 与主项目的边界

1. **主项目只读**：`sandcore/` 与根目录任何文件不修改、不删除、
   不回滚；所有产物只写 `ext/`。
2. 平台文件（`SCAPI.H`/`NUI.inc`/`SCMEM.inc`/`SCMEM.H`/`mkscx.py`）
   拷贝进 `libex/`、`tools/` 使用，**原样不修改**，头部注明来源；
   上游更新时重新拷贝并回归。
3. 唯一内核 ABI 是 SCAPI.H 的系统调用；扩展代码**零新增系统调用、
   零内核改动**。扩展的"生态位"是补用户态功能空白。

## 2. 分层与复用

- `libex/`：跨包共享库（界面附加控件/表达式/CSV/配置/音频/图标）。
  改库 = 改合同 = 升版本 = 各包同步回归；API 合同以
  [libex/LIBEX.md](libex/LIBEX.md) 为准。
- `tools/`：构建工具（图标编译、载荷冻结、SCX 封装）。
- `SoftwarePackN/`：包专属一切（源码/图标/配置模板/manifest/
  安装器/文档/dist）。**跨包可能不复用的东西都放包内**。

## 3. 工程质量纪律（红线）

1. freestanding：无 libc/libm/libgcc；**禁 64 位除法与
   double↔i64 转换**（libgcc 符号会断链）；禁 stdint/VLA/
   复合字面量。
2. 允许浮点（目标机完整 x86，内核保存 FPU 上下文）；数学函数
   自实现（sin/cos 建表、牛顿开方）。
3. 错误处理一律"显式失败优于静默错值"：解析拒绝尾随垃圾、
   写文件核对回执、坏图标宁可空块不越界。
4. 全中文注释解释**为什么**；命名前缀分模块（ex_ 共享、应用内
   两字母前缀）；颜色只走主题角色/调色板语义槽，不写裸色号
   （游戏固定材质除外，需注释声明）。
5. 事件循环节能：NUI `ui_frame_due_interval` 契约——静止不重绘、
   hover 进出才重绘；游戏固定步长仿真与渲染解耦。

## 4. 安装包合同

- 交付形态：**每个包一个安装器 SCX**，应用与图标全部内嵌
  （mkpayload.py 冻结，CRC32 双向校验）。
- 安装器必须提供：组件勾选、**安装目录可自选**、桌面快捷方式
  与默认配置的开关、进度与结果页、已装检测 + 卸载（含菜单项
  剔除与配置清理选项）。
- 配置文件只在缺失时写默认值；更新绝不覆盖用户配置。
- 程序菜单项先写候选 + `sc_config_check` 纯校验 + 通过才替换
  `SYS/MENU.CFG`；失败跳过不报错打断。
- 图标：像素画 `icons/<app>.txt` → mkicon.py → SCB2；一份图标
  三处使用（应用 SCX bit1 内嵌 / SYS/ICONS 落盘 / 安装器预览）。
  Classic/Aurora 的桌面渲染差异由内核负责，不做两套图标。
- 配置模板放 `cfg/`，格式统一 `key=value` + `#` 注释
  （ex_cfg_build 生成文件头）。

## 5. 状态声明纪律（继承主项目规则）

- 每个包 README 必须有"验证状态"节：区分"已验证"（语法/链接/
  封装/头核对）与"未验证"（客体内行为/性能），**不把宿主构建
  通过说成实机可运行**。
- 上机验证后回填证据与日期；发现缺陷在本目录修复并登记，
  不动主项目。

## 6. 命名与格式

- 应用名：包内唯一、SCX 主名大写（PCALC/SHEET/...）；快捷方式
  标签用产品名（PCalc/SandSheet/...）；配置文件名独立映射
  （见 manifest 第 7 列）。
- 文本：源码 UTF-8；UI 字符串只用 ASCII（凤凰字库汉字有限）；
  文档中文。
- 自定义格式魔数带 `MIO` 署名尾缀（与主项目一致）。
