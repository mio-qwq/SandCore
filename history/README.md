# 历史源码与工程输入

从本机build目录、试玩目录和历史ZIP中只提取源码、脚本、文档、许可证及
影片工程输入。每份不同内容保存一次，[INDEX.json](INDEX.json)记录全部原路径、
保存路径、尺寸及SHA256；与当前工程/版本快照完全相同的文件直接引用已有路径。
`objects/`中的散列文件名用于去重，原扩展名保留，全部来源在索引中可查。

包括旧版本候选/失败方案、独立验证夹具、用户试玩PoC、旧渲染脚本/着色器及
Blender工程输入；它们保留历史状态，不接入当前产品构建，不改称已发布功能。
当前正式源码入口为`sandcore/`，版本快照在`snapshots/`。

镜像、视频、渲染帧、宿主下载工具及缓存留本机；每版一次运行镜像在`releases/`。
历史外部组件保留现有工程中的原许可证/来源声明，遵守AGENTS第十节。
