## M8：Welcome to true color.（源码，未验收）

总时间轴42秒，PIT驱动镜头/轨道物体；每个客户区物理像素实际
发射射线，与球/轴对齐盒/地面求交，另发太阳遮挡射线，最多两次
反射。反射/阴影随场景和镜头变化，不是预录贴图或屏幕固定黑块。
金属、车漆、石、木纹、瓷面、玻璃色与水镜使用GFX已登记端点，
高光/Fresnel与世界锚定纹理由SCENE计算。玻璃色为反射近似，
不承诺物理折射、HDR或GPU硬件光追；World另有实际体素透射。

| 时间 | 幕名 | 场景与镜头 |
|---|---|---|
| 0–6秒 | THE FIRST LIGHT | 石/木/金属工作台，金属主球、细石珠接触阴影；侧向推镜 |
| 6–14秒 | MATTER AND REFLECTION | 车漆、金属、玻璃色球体与材质参照，环绕观察 |
| 14–22秒 | OPEN HORIZONS | 实体柱列/梁、开阔水镜、真实柱影与反射，横向移动镜头 |
| 22–30秒 | A SPACE TO CREATE | 三件实体创作面板及底座，细金属边与石台；浮动与推镜 |
| 30–36秒 | EVERY COLOR, ALIVE | 12颗轨道小球围绕主球，不同颜色/尺度与连续空间运动 |
| 36–42秒 | WELCOME TO TRUE COLOR. | 主球、两侧材质球、收束镜头，原生凤凰片名与mio署名 |

Space暂停/恢复、R重播、数字1..6跳幕、Esc退出；鼠标Pause/Play、
Replay和可见幕选择。`run APPS/LUMEN.SCX 3`保留从第三幕开始。
页脚显示实际宽×高与上一帧tick×10ms，不是宿主FPS。字形直接
绘入物理帧，标题局部倍率不改变射线尺寸。行批次检查Esc，窗口
关闭由内核结束任务。第二阶段须录相邻帧及真实时间检验连续性。

这是重大版本的视觉庆祝，目标为顶级画面。第二阶段必须依据实际
画面完善节奏、过渡、构图、材质与丰富度，不能只因六幕代码存在
就宣布宣传片完成或现代写实光追达标。

## M7：Welcome to Graphics（已验证历史）

这是在沙核内实时计算的 42 秒开场动画。窗口每次提交一张完整软件帧，
主题是从基本窗口绘制走向可自定义的进阶图形。它用同一套三环图形能力
表现片名、透视、面光照、材质、空间、粒子、工具界面与转场，没有预存
视频代替几何计算。VGA 13h 仍为 320×200，客户区 318×170；它不是 GPU
加速或高清电影，画面设计以低分辨率下的构图、节奏与色彩辨识为目标。

| 时间 | 段落 | 主体与构图 |
|---|---|---|
| 0–6 秒 | A new chapter | 深蓝星场、轨道、渐次出现的英文大标题、中文片名、暖金细线 |
| 6–14 秒 | Light / geometry | 左侧节奏化文字、右侧二十面晶体、面光照、轨道与卫星 |
| 14–22 秒 | Space / material | 暖日/远山/冷色流动三角地形，展示可塑造的空间 |
| 22–30 秒 | Design / build / play | 三层软件界面卡片从侧面入场，源码/现场/世界文件形成层次 |
| 30–36 秒 | A world you can shape | 三维粒子星座、空间轨道与主题句 |
| 36–42 秒 | Welcome to Graphics | 晶体、双语片名与 SandCore M7 / mio 收束，结尾保持 |

Space 暂停/恢复时间轴；R 重播；数字 1..6 重看对应段；Esc 退出。
命令 `run apps/lumen.scx 3` 可从第三幕开始，用于人工欣赏与截图检查。
段落转场保留上一张真实帧，通过斜向青金光幕露出下一幕，再整帧提交。
时间取 PIT tick，渲染慢时不会把短片长度按帧数无限拉长。

调色遵循 GFX.md：深蓝背景提供留白，青色表现几何/光，暖金用于线索、
日光与庆祝意味。每幕限制主角数量，界面卡片只作动画场景示意，不冒充
调试器的真实 CPU 数据。真实调试功能由 apps/debugger.scx 提供。
中文片名只通过 tools/import_font.py 补九字；原 27 字点阵核对不变。
