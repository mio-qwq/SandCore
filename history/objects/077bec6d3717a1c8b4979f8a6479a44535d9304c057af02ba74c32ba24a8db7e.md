# SandCore 项目代理约束（ZCode 给自己立的规矩）

> 本文件是工作区级常驻指令。用户明确要求把以下约束持久化，每次会话开工前先读这里。

## 一、审美约束（用户 2026-10-01 明确要求：保持高审美）

1. **一切用户可见的东西必须被"设计"过**：开机画面、桌面、图标、窗口、游戏 UI、
   命令行提示，都要讲究构图——层次（前景/中景/远景）、渐变、留白、色彩情绪统一。
   截图要经得起看，能一眼看出"有人用心画过"。
2. **配色纪律**：颜色一律走 `docs/GFX.md` 的调色板槽位分配表，新颜色先入表再使用，
   禁止在代码里随手写裸色号。
3. **字体即门面**：SCF 点阵字形逐位手绘、风格统一（字重、圆角风格、字面大小一致），
   新字形先在 8×8 网格上起草再入库。
4. **代码同样要美**：命名一致、注释解释"为什么"、模块职责单一、公共接口先写头文件。
5. 界面文案克制：能一行说清的不写两行；装饰服务于辨识，不堆砌。

## 二、里程碑流程约束（每个里程碑都必须走完）

1. 实现 → 构建 → **无头 QEMU 自动化验证**（HMP sendkey 驱动输入 + screendump 截图为证）。
2. **向用户提交验收包**：截图 + "怎么验证的"说明 + 本里程碑变更清单。
3. 验收通过后**同一批次内持久化文档**：README 状态表、对应 docs/*.md 规范、
   文档末尾修订记录各加一行。文档与代码不许脱节。
4. **没有验证证据，不得宣布完成**。"应该能跑"不算跑。

## 三、环境与工程约定

- QEMU 一律用 Windows 版（`C:\Program Files\qemu`，用户要看窗口）；编译主力是 WSL
  Ubuntu（ELF 工具链），MinGW 为备用——见 docs/BUILD.md。
- 全中文注释，解释"为什么"；自定义格式/布局/ABI 改动必须同一批次更新对应 docs。
- 批处理文件(.bat)内容纯 ASCII（cmd 按 GBK 解析，UTF-8 中文会变成乱码命令）。
- 内核禁用浮点与任何 libc；跨文件常量（如 KERNEL_SECTS）改动前查 docs/BOOT.md 同步清单。

## 四、用户空间兼容铁律（用户2026-10-02明确追加）

- **SCAPI.H的API和ABI只增不减**：已发布入口、功能号、寄存器含义、
  返回值与缓冲布局保留。新增能力使用新调用号或独立带版本快照。
  旧调用忽略的寄存器仍忽略，不能用它们悄悄加入新选项；旧三环
  程序无需重新编译继续运行。改动须同步SYSCALL.md及对应功能规范，
  并实际运行历史程序/检查旧缓冲边界。

## 六、性能与实现效率硬要求（用户2026-10-03明确追加，重要）

1. **性能优秀、效率高是实现质量要求，复杂系统尤其必须重视。** 实现时就审查算法复杂度、数据布局、内存分配/复制、磁盘I/O、逐像素计算、输入采样与调度，不能以QEMU宿主CPU较强为理由保留明显无效工作。
2. 高频路径优先减少重复计算与全量处理：静止/隐藏工具不持续整帧重绘，未改变控件外观的鼠标移动不触发无效客户帧；循环内避免重复分配，采用批处理、局部损伤、事件让出与适当空间索引。保持输入边沿、拖动/绘画、焦点、尺寸、主题与状态更新即时正确。
3. 缓存必须有明确失效与资源归属。世界编辑/读档/新世界、光源与相机变化、主题/尺寸变化、任务退出或槽复用不能使用陈旧结果。复杂热路径写详细中文原因注释，解释规模、生命周期和失效条件。
4. 先据实际测量定位成本，再在**相同画质、功能、数据规模与输入**下对照优化。分别记录客体PIT采样、宿主QEMU一核心CPU、帧耗时/输入延迟及长尾、真实像素与页回收；不把100Hz时钟等同帧率，不凭CPU百分比断言硬件原因。
5. 不通过暗降渲染尺寸、删光源/反射/阴影/玩法、伪造空闲统计来提速。旧LEGACY原字节、SCAPI.H API/ABI、VGA及设备回退保持。内核无浮点/libc的约束不因优化解除；SIMD/FPU等新支持须有独立状态/兼容合同与实际收益依据。
6. 实质性能改动在第二阶段做可复现的无头双盘QEMU前后对照、正确性/边界/兼容回归及截图，并同步PERFORMANCE.md/对应规范/当前接力状态。没有数据不能称性能达标；小夹具收益不能冒充全组件、高清游戏或整机丝滑。
7. **2026-10-04资源预生成授权**：用户允许在充分优化算法后，提前生成部分游戏资源以代替昂贵的重复实时生成/渲染；可采用材质、静态照明/远景、几何与视角资源缓存。此授权不能作为偷懒理由，视觉质量/原生清晰度/玩法不得降低；明确空间成本、失效/重建与实际收益。动态遮挡、世界编辑、相机/昼夜/材质变化须保持正确。宣传片执行下节最新独立授权。
