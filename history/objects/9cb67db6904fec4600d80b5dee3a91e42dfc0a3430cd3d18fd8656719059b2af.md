# M9 FLAC播放器测试快照

双击上一层的 `run-m9-flac.bat`。这是新增的独立试玩入口，原 `run-m9.bat` 和旧会话均保留；新入口独立保存自己的会话，每次沿用最近一次试玩盘，`--fresh`从随包基线开始。

播放器支持 MP3 / WAV / FLAC。串口中运行：

```
/APPS/SOUND.SCX /TMP/ALBUM.FLAC &
```

ALBUM.FLAC 是本项目原创的1.25秒测试音和原创测试封面，便于直接确认显示；不是正式音乐。自己的音乐可 `:put "C:/music/song.flac" /HOME/SONG.FLAC`，再运行 `/APPS/SOUND.SCX /HOME/SONG.FLAC &`。

- `M`或Mini：缩到左下角；Expand/M恢复原大小。
- `F`或Full view：最大化；Space播放/暂停；R重播；O选曲。
- 迷你模式打开浏览器会临时展开，选曲/取消后回到左下角。
- 读取FLAC内嵌PICTURE、MP3内嵌APIC，或同目录cover.png/cover.jpg/folder.png/folder.jpg。没有封面时显示主题唱片图。
- `:put`和`:get`显示进度、速率、ETA；校验和提交/保存完成才标完成。示例 `:get /HOME/SONG.FLAC "C:/music/received.flac"`；下载不会覆盖已有本机文件。

正常退出串口工具输入`:quit`；QEMU关闭后数据仍在本目录sessions中。M9完整80% CLI行为及完整安全/故障/性能矩阵还未验收，本包是测试快照。所有第三方固定源码和原始声明在客体SYS/LICENSE，新增dr_flac采用MIT-0；独立宿主编码测试工具未随包分发。
