### B. 三环异常与注册处理器

依次 run apps/probe.scx div、ud、page。每次出现 APPLICATION PAUSED
诊断卡，分别向量 00/06/0E；任务栏时钟继续增长。关卡片的红叉才结束
该程序，回到 Shell，不需要重启。重复测试不应耗尽任务槽。
run apps/probe.scx handler，应显示 HANDLER RESUMED；处理器修正
真实 UD2 现场并恢复执行，home/handled.ok 为 PASS。
M6 的 apps/panic.scx 在 M7 同样只暂停三环任务，旧红屏步骤是历史记录。
内核/零环模块自身异常仍属于内核 panic，不宣称零环故障也被隔离。

### D. 系统内 C 编译与三代自编译

以下每条分别输入，等待编译窗口关闭、Shell 获得焦点后再输入下一条。
成功有 SCCC OK 日志，HOME 中新增 .SCX、.log、.map 文件。

```text
run bin/s3c.scx home/FEATURE.C HOME/TEST.SCX
run HOME/TEST.SCX
run bin/s3c.scx SYS/SRC/s3c.c HOME/S3C1.SCX
run HOME/S3C1.SCX SYS/SRC/s3c.c HOME/S3C2.SCX
run HOME/S3C2.SCX SYS/SRC/s3c.c HOME/S3C3.SCX
```

FEATURE 程序运行后 home/C-RESULT 为 PASS，Esc 关闭。最后一条是
真实第二代编译器生成第三代，不能省略开头 run 或路径的前半段。
自动化会逐字节比较三代产物；源码/限制/18 组语言测试见 C.md。
编译器已支持基本整数 C 和宏；不把浮点/libc/完整 ISO C 宣称为已支持。

### E. 图形 IDE

run apps/ide.scx。默认 Hello 源码；箭头移动任意位置，ASCII/Enter/Tab
插入、Backspace 删除。F8 到开头、F9 到结尾，与编辑控制字符分开。
F1 打开、F2 保存、F3 新文件、F4 返回源码、F5 内部编译、F6 运行、
F7 调试。未保存时 Esc 会询问 Y 丢弃/Esc 保留。源码最多 65535B。
先 F5 等成功，再 F6；程序关闭后点任务栏切回 IDE。改出一个未知变量
再 F5，应显示带源文件/行号的诊断，F6 不应运行以前的旧成功文件。
run apps/ide.scx home/demo.asm 后 F5 是内部 SandAsm，不需手动关闭
编译窗口；成功后可运行/调试。原生已收汉字在编辑区按 16px 字形显示。

### F. 文件管理器与核心保护

run apps/files.scx HOME，N 输入 HOME/PLAY 回车创建空目录；选择它
Enter，进入应为空；Backspace 回 HOME。F2 输入新的完整路径重命名或
移动，X 后 Y 确认删除；非空目录会失败。F5 刷新，j/k 或上下选择。
SCX Enter 运行、D 调试；文本 Enter/F4 进 IDE。显示省略不截断实际路径。
到 SYS/CORE，尝试改 CORE.SKM 应显示 Core path protected by kernel；
直接系统调用也返回 -5。保护不只是一项文件管理器按钮限制。
SYS/MOD 是自定义零环模块目录：SKM 格式与风险边界见 MODULE.md；
它们开机执行零环代码，有完整内核权限，格式合法不等于代码安全。

### 自动复现与证据判读

```text
build.bat
python tools/verify_m6.py all
python tools/verify_apps.py
python tools/audit_m6.py
python tools/package_m6.py
```

分别顺序执行，不要与另一台使用 4444/4445 监视器端口的 QEMU 同时运行。
两个脚本均直接启动 Windows QEMU，复制 build/sanddata.img 为测试盘，不往实际工作数据盘注入测试文本。
HMP sendkey 驱动键盘、QMP 分沿注入鼠标、HMP screendump 保存证据；pmemsave 和磁盘读取只用于诊断断言。
Mines 胜负用读取雷区的测试诊断驱动完整揭格，不改变程序的布雷/揭开逻辑；不是声称人工盲玩获胜。
壁纸验证使用 HMP system_reset，再实际走开机按键和 wm_init 配置读取，排除“只修改内存”的假成功。

结果与截图：M6a 在 `build/m6a/`，M6 在 `build/m6/`；各有 results.json 与完整 qemu-command.json。
应用矩阵共 24 张截图，包括非法指令/超长符号/非法入口、保存重读/F3、文件打开、除零/溢出、扫雷旗标/胜负、重启壁纸。
截图说明与限制见 [M6.md](M6.md)、[ASM.md](ASM.md)、[APPS.md](APPS.md)。
