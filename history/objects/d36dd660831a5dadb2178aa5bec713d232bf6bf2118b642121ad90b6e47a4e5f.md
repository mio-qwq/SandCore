# Welcome to Graphics：M7 实时图形短片 v0.2

> 作者 mio。程序 apps/lumen.scx，源码 user/lumen.c。真实 G2 编译产物已通过
> 六幕截图、连续帧、暂停与重播测试，证据 build/m7-graphics/film-*.png。

M8最终短片为 **Welcome to true color.**，在普通三环程序内连续
实时生成真彩色画面，包含真正射线交点、阴影、反射和写实材质，
设计丰富镜头/过渡/构图；不能用预录视频或静态图片充当实时渲染。
本页M7短片与旧原生SCX继续保留，不能把其投影几何改名称为光追。
新片尚未实现，需登记实际内部渲染尺寸、每帧耗时/实测速度、系统
内SCCC生成来源及真实连续画面证据，最新范围见M8.md。

这是在沙核内实时计算的 42 秒开场动画。窗口每次提交一张完整软件帧，
主题是从基本窗口绘制走向可自定义的进阶图形。它用同一套三环图形能力
表现片名、透视、面光照、材质、空间、粒子、工具界面与转场，没有预存
视频代替几何计算。VGA 13h 仍为 320×200，客户区 318×170；它不是 GPU
加速或高清电影，画面设计以低分辨率下的构图、节奏与色彩辨识为目标。

| 时间 | 段落 | 主体与构图 |
|---|---|---|
| 0–6 秒 | A new chapter | 深蓝星场、轨道、渐次出现的英文大标题、中文片名、暖金细线 |
| 6–14 秒 | Light / geometry | 左侧节奏化文字、右侧二十面晶体、面光照、轨道与卫星 |
| 14–22 秒 | Space / material | 暖日/远山/冷色流动三角地形，展示可塑造的空间 |
| 22–30 秒 | Design / build / play | 三层软件界面卡片从侧面入场，源码/现场/世界文件形成层次 |
| 30–36 秒 | A world you can shape | 三维粒子星座、空间轨道与主题句 |
| 36–42 秒 | Welcome to Graphics | 晶体、双语片名与 SandCore M7 / mio 收束，结尾保持 |

Space 暂停/恢复时间轴；R 重播；数字 1..6 重看对应段；Esc 退出。
命令 `run apps/lumen.scx 3` 可从第三幕开始，用于人工欣赏与截图检查。
段落转场保留上一张真实帧，通过斜向青金光幕露出下一幕，再整帧提交。
时间取 PIT tick，渲染慢时不会把短片长度按帧数无限拉长。

调色遵循 GFX.md：深蓝背景提供留白，青色表现几何/光，暖金用于线索、
日光与庆祝意味。每幕限制主角数量，界面卡片只作动画场景示意，不冒充
调试器的真实 CPU 数据。真实调试功能由 apps/debugger.scx 提供。
中文片名只通过 tools/import_font.py 补九字；原 27 字点阵核对不变。
