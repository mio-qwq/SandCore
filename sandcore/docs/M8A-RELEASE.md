# SandCore M8a 发布说明

作者 **mio**，发布日期 **2026-10-04**。

**M8a 现在正式发布现有成果。** 用户明确认可本轮真彩色和用户组件已经够用、表现优秀，并授权将当前版本命名为 M8a。完整 M8 中尚未达到预期的部分暂时封存；这是用户批准的收束，不是声称原完整目标全部达成。

## 1. 发布内容

发布包为 `build/SandCore-M8a-2026-10-04.zip`，同名 `.sha256` 为整个压缩包摘要。解压保留工程层级，进入 `sandcore` 双击 `run.bat`；无需重新构建。默认启动优先 WHPX，保留 `run.bat tcg`，明确硬件模式用 `run.bat whpx`。Windows QEMU 位于 `C:\Program Files\qemu`；引导盘仍必须 `if=floppy`，数据盘仍为 IDE，128MB、单个虚拟 CPU、原设备回退保留。

主要成果包括：

- RGB/ARGB32 真彩色、高分辨率与缩放、透明彩色图标、主题/窗口和可配置桌面/菜单。
- Settings、Lens、Canvas、Monitor，原工具适配和默认高清三棱镜 PNG。
- 新 Shell、配置用户名与 `/BIN:/APPS` 搜索路径、19 个独立 CLI、真实 CPU/卷信息。
- 输入/帧复制/调度/局部合成优化，SCCC 和通用整数/图形/内存库改进。
- 当前游戏扩充、原实时动画、离线 Blender/OpenCL 工程和相应成功/失败证据全部保留。
- 旧 SCAPI.H API/ABI、用户指定字体、M6/M7资料、LEGACY 原字节、VGA/PS2/ATA 回退保留。

包内含源码、资源、完整中文规范、现有开发双盘与匹配内核诊断文件、资源树、已有阶段报告及精选真实截图。已验收 M7 包保留为独立历史基线，不将其重建后改称原版本。

## 4. 保存与完整性

发布包根 `M8A-MANIFEST.json` 逐项记录实际文件大小/SHA256、发布范围和未达成预期；逐项从 ZIP 重读核对 CRC、大小与摘要。外部 `build/m8-frozen-20261004-01/package-result.json` 记录本次归档完整性与整个 ZIP 摘要，**PACKAGE_BYTES_VERIFIED 不是功能或性能全项通过**。

完整 build 中约32.6GB的历史镜像/截图/渲染帧原地保留；包内 `BUILD-HISTORY-INDEX.json` 提供原路径、尺寸、修改时间索引。这些历史大文件没有全部复制进发布 ZIP，各批原件/既有摘要与不可变证据仍在原工作区。用户 `temp miotest` 双盘/存档未改变。
