# M9 正式发布

用户于2026-10-05明确“验收通过”，M9正式发布。版本范围为已确认的Windows QEMU
音频、UID/GID/rw、SandFS v5、外部双UART/SYSTEM/Ring0调试、独立CLI及开发闭环、
整数SSE2与窗口截图，以及后续明确追加的FLAC/封面/迷你播放器和传输进度。

CLI按用户选定的本地140/171参考名及公开支持子集验收；完整310行对照与缺项保留。
网络留M10、GPU暂缓；M10完成时才冻结基础内核。原M8未达成目标按原决定继续封存。

验收范围、原生编译、故障/边界、连续生命周期、截图、性能与历史观察项见
[M9-ACCEPTANCE.md](M9-ACCEPTANCE.md)。一次早期串口心跳超时根因未确认、后续40生命周期
未复现的记录继续保留；用户验收不会把未覆盖的物理硬件或其它观察改称已验证。

继续使用`releases/SandCore-M9-build.zip`原验收镜像，不改原字节或摘要。
五份源码独立重建及当前仓库输入自足性见[REBUILD-VERIFICATION.md](REBUILD-VERIFICATION.md)。
根目录的`sanddata_editor/`子项目另外提供用户要求的自写C/Win32宿主SandFS镜像编辑器，
见[使用说明](../../sanddata_editor/README.md)，支持浏览、双向拖放、删除、改名和备份保存。
