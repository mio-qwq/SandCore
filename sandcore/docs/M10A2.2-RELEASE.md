# SandCore M10a2.2 — SandFS 目录写回修复

2026-10-17。M10a2.2基于M10a2.1，仅更新文件系统修复内核及对应文档；原M10a2、M10a2.1的tag、Release、附件全部保留。下载入口：[M10a2.2](https://github.com/mio-qwq/SandCore/releases/tag/M10a2.2)。

## 修复内容

普通SCCC编译经旧写入接口创建SCO、map、log时，新目录记录可能带有复用内存中的名字尾部；新版目录序列化原样复制64字节后，卷虽然CRC正确，loader和SandEditor仍会因非法文件名拒绝它，造成使用时正常、重启失败。

功能源码只改`kernel/fs.c`：创建文件或目录时初始化完整记录，写入/重命名清理名字，序列化逻辑名字后规范补零。保持SandFS格式、双bank提交顺序、SCAPI.H原字节和全部公开API/ABI；不改变用户态程序或系统库。主内核与恢复内核均使用已构建的修复CORE，SHA256为`827a9e81e5e33a9f70e695ff579c50b7605a7d088fb90fc138657410e832ef68`，修复源码提交为[60a36d0](https://github.com/mio-qwq/SandCore/commit/60a36d00cfe8e09eebc427cf7dcdaf9f4b6d98e4)。

## 产物与使用

- 运行包仍严格四文件：`run.py`、`run.bat`、`sandcore.img`、`sanddata.img`。解压后运行`run.bat`；宿主仍需Windows QEMU和Python。启动脚本与引导盘复用M10a2.1原字节。
- 数据盘来自M10a2.1干净发布盘，只换入修复主内核/恢复内核并同步SDK文档，保留其它对象；不使用或上传用户个人test盘。
- SDK沿用M10a2.1的编译器、链接器、9个库、公共头、例子与许可证原字节；增加本补丁和文件系统规范，同步SDK版本说明及清单摘要。旧编译来源记录保留，不把复制文档说成重编译。
- 已有个人盘请先备份并保留文件；不要用干净发布盘覆盖个人盘。此次干净镜像用于新安装，用户本机test盘已另行恢复并安装相同修复内核。
