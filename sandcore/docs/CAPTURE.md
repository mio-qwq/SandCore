# M9 指定窗口截图

> 当前验证范围已更新，见末尾“2026-10-05 M9最终验证记录”及[M9验收报告](M9-ACCEPTANCE.md)。早期未验证/待验标记保留阶段背景。

> 初版实现已写，未构建/运行。历史宿主截图不代表本API有效。

CAPTURELIST列出调用者可读的窗口：句柄、PID、客户宽高、标题。本人同UID窗口
可截取，root可读普通用户窗口；SYSTEM窗口另要求外部串口SYSTEM管理资格。
截图对象由内核分配，token绑定申请者PID及代数，不接受用户提供canvas地址。

CAPTUREOPEN复制真实客户画布，在复制期间固定任务/CR3和窗口生命周期，允许
硬件IRQ收输入。快照保留原生尺寸与BGRA像素/透明度；VGA索引通过系统调色板
转换成不透明BGRA。快照不含外框、光标、被其它窗口遮挡的合成结果。
返回32字节版本1快照：版本/窗口句柄/宽/高/字节stride/格式2/正文bytes/owner代数。
后续窗口关闭、调尺寸、置顶不改变已复制的快照。最多8份，总预算64MiB，分配
失败返回-4；不缩小截图。READ分块最多64KiB，CLOSE或申请者退出释放全部页。

`capture`无参数列窗口，`capture 句柄 /HOME/window.bmp`保存BMP V4，top-down、
32bpp与RGBA掩码保留透明度。正文流式写事务，读取/写入失败则取消。外部调试机
随后使用`:get /HOME/window.bmp 本机新文件.bmp`，SHA-256核对后读取本机产物。
