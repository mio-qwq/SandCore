# Studio 2 使用说明

Studio 是 C 程序开发工具。只写一个程序时，直接新建或打开 C 文件即可；项目用于组织多份源码、构建设置和布局，不要求初次使用就编写配置文件。

## 写第一个程序

1. 在“开始”页选择“新建程序项目…”。先选择保存文件夹，再输入项目名称并选择“C 控制台程序”。名称不需要扩展名。
2. Studio 创建项目文件夹、`MAIN.C`、`.SCW` 项目和 `BUILD` 输出文件夹，打开可以直接编译的 HelloWorld 源码。
3. 按 **F7** 构建。下方“输出”显示编译、链接及保存结果；成功后显示输出路径。
4. 按 **Ctrl+F5** 运行，程序输出也显示在下方。按 **F5** 用调试器启动。运行或调试之前如源码有改动，Studio 先构建，成功后才启动。

只写单个文件也可选择“文件 → 新建 C 源文件…”或“打开文件…”，不必先建项目。新建 C 文件自动补 `.C`，新建头文件自动补 `.H`。打开 C 文件后可以直接构建；单文件的程序输出默认保存在 `/HOME`。项目树组织多文件，增加文件后按整个项目构建。

文件对话框显示当前文件类型。双击文件夹进入，Enter 也可进入；“选择文件夹”提交目录，“取消”退出。新建时名称不需要猜后缀；重名不会静默覆盖。

## 错误、已有程序和高级项目

编译失败时查看下方输出中的具体文件、行号和编译器原文。诊断列表可跳转到相应源码。缺头文件、路径不可读取、权限或链接符号错误会报告原因。失败不会启动上次遗留的旧程序。

`#include <stdio.h>` 等标准头及系统公共头可直接使用。旧源码的 `SCAPI.H`、`SCIO.H`、`SCMEM.H` 继续位于 `/SYS/INC`，其中 `SCAPI.H` 保持冻结原字节。保留兼容不代表扩展旧 ABI；新 API 仍通过 SC32API 和系统库提供。

普通 C 程序自动识别实际 SCO 符号和系统 SCL 导出，生成内部链接清单；不需要用户手写 JSON。多文件仍各自编译为 SCO，再由真实链接器连接。第三方库、自定义导入/导出或 SCL 库目标可在“工程 → 项目设置（高级）…”关闭自动链接并指定显式链接清单。已有 SCW 项目及 ResearchDesk 应用、插件流程继续支持。

`.SCW` 是项目文件，`.C` 是 C 源码，`.H` 是头文件，`.SCX` 是程序，`.SCL` 是共享库。库目标需要实际宿主程序才能运行或调试。编译器、链接器和临时文件夹由默认配置管理；路径过长或无写权限时报告具体错误。
