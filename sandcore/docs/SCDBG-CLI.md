# M9 scdbg CLI（源码，未验证）

> 当前验证范围已更新，见末尾“2026-10-05 M9最终验证记录”及[M9验收报告](M9-ACCEPTANCE.md)。早期未验证/待验标记保留阶段背景。

`scdbg [--map FILE.map] PROGRAM [ARGS...]`由DBGSPAWN2创建真正的三环目标，
首指令前绑定调试owner并暂停。纯命令行入口`user/m9/scdbg.c`，私有核心
SCDBG.H/inc，旧`debug`命令名复用同一功能，不把两个命令名计作两项覆盖。
与外部COM1 Ring0调试分别交付；scdbg不能调试内核、不能连接客体UART。

| 命令 | 行为 |
|---|---|
| regs / status / where | 88B真实现场/运行状态/可选MAP最近符号 |
| step [N] / cont / pause | 真TF/继续/内核保存现场暂停；N最多10000 |
| break HEX / clear HEX / breaks | 真INT3插入/恢复，内核最多8个三环断点 |
| mem [HEX] [LEN] | 最多256B映射检查后的hex/ASCII |
| stack [N] | 最多64个u32，逐4B检查，未映射显示???????? |
| code [HEX] [LEN] | 自写i386辅助子集，未知/短/未实现前缀显示db原字节 |
| input TEXT / eof | 独立目标stdin管道，有界待发队列；EOF在队列排空后关闭 |
| restart / quit | 结束并领取旧作业、重新首指令暂停 / 结束专属目标与回收 |

地址十六进制，长度/计数十进制。没有实现任意寄存器写入、内存写入、完整
SSE反汇编或跨进程attach；旧DEBUG ABI保持原8种命令，不偷偷加新语义。
带空白的程序路径明确拒绝，后续参数重新引号序列化并支持空白/反斜杠/引号。

作业票据绑定父/子代数；每次操作先读WAIT2，不用旧8行CPUINFO定位32槽目标。
结束读取消费票据后丢弃旧PID，不能将新槽占用者当原目标。提示符空闲每5tick
检查状态，真正步进后读取目标保存现场。step最多等待100tick，若系统调用尚未
返回则报告仍运行，不能显示旧暂停帧当新结果。

暂停目标无法读取stdin，输入命令最多保留4096B待发正文，加上内核4096B管道。
队列满明确拒绝新命令，提示符始终还能继续/暂停；不在写满后无限等目标读取。
目标stdout/stderr沿已有标准流，可与调试提示混排，当前未做独立输出面板。
