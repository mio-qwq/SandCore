# SCLDR v1 用户态动态装载器

对应 `user/runtime/SCLDR.H`、`scldr.c` 与私有 `scl_platform.c`。这是 SandCore M10a2 — The Application Platform Era 的引导切片；当前构建/客体状态以 `M10A2-IMPLEMENTATION.md` 为准。

## 1. 应用与引导平台接口

`ScRuntimeCreate` 接受带精确 size 的平台回调表，分配独立的每进程上下文。正式引导后端只负责文件读取、普通元数据页和模块映像页分配/保护/释放。`ScRuntimeDefaultPlatform` 通过已存在的 `start.asm` 私有桥和新模块调用工作；正常应用只包含完全大写 `SCLDR.H`。

`ScRuntimeOpen(runtime,name,abi_major,min_minor,min_version,&handle)` 要求规范库名和兼容版本。声明名称须与请求相同；同上下文重复装载复用已有实例。外部句柄引用与库依赖边分别计数，不能用猜出的依赖句柄撤销另一库的引用。函数/数据查询要求导出种类相同；导入还检查要求的最小数据尺寸。

`ScRuntimeSymbol` 首次返回函数或数据地址时固定模块直到进程正常结束，依赖边保持其闭包。因为地址可保存在任意应用数据和回调中，仅检查当前 EIP 无法安全认定已无使用者。`ScRuntimeClose` 释放一次外部引用，仍驻留返回 1；无引用且未固定时，先确定失去最后引用的整个依赖闭包，再按实际初始化链逆序运行 fini，全部回调结束后归还映像/元数据。预先装载的共享依赖也遵守其真实初始化顺序。

`ScRuntimeDestroy` 由 CRT 在 main 返回并停止所有库回调后调用，按初始化的逆序调用 fini，再释放所有模块。调用期间禁止重入装载器，返回 `SC_SCL_BUSY`。异常终止不调用可能损坏的 fini，由内核回收全部私有模块/堆页。v1 没有不安全的强制热卸载；启动自动导入与 SCCC 输出仍须独立接通。

## 2. 装载事务与回滚

1. 完整读取受权限约束的文件，严格验证所有表、偏移和符号，再创建私有模块实例。
2. 保存元数据，分配/清零映像，搬入各段，释放文件副本。
3. 用模块内父链和游标迭代深度优先解析依赖，遇到仍在 LOADING 的祖先即拒绝依赖环；没有递归栈深度或固定模块槽位门槛。
4. 在依赖完成后解析函数/数据导入，按 `S+A`、`S+A-P` 写入重定位字。
5. 整个映像先变为只读，再开放 data/BSS 的可写页，调用 init。依赖先初始化，再初始化使用者。
6. 全部成功才返回外部句柄。任何读取、版本、符号、分配、保护或 init 失败，先逆序调用此次成功初始化模块的 fini，再还原旧模块的依赖计数并释放所有新资源。

失败不改变调用者的输出句柄。成功初始化链与实例建立链分别维护，不能把两种顺序混用。init 返回非零时，该模块自身须清理 init 内部尚未提交的用户资源；它的 fini 不作为成功初始化回调调用。装载器负责它的映像/元数据和依赖回滚。

## 3. 映射与路径边界

模块使用 `0x50000000..0x53ffffff`，元数据使用已有图形/用户堆。每进程独立物理页。text/rodata 只读；data/BSS 可写；没有 NX，不能声称完整 W^X。内核 syscall 输出检查 RW，正常读取继续允许只读字符串；受拥有者与代数约束的断点单字节修补是专用调试例外。

默认系统目录为 `/SYS/LIB`。显式 package_root 必须是绝对路径，寿命覆盖整个 runtime；第三方库从该目录读取。SC32API、SCCLIB、SCLIB、SCUI、SCSHELL、SCGFX、SCRES、SCLDR 等保留库名固定从系统目录读取，忽略包目录。无 CWD、PATH 或同名回退搜索。目录权限仍由 SandFS 执行；root 的既有文件管理资格不等于外部 SYSTEM 的 CORE 管理资格。

## 4. 错误与观测

| 值 | 名称 | 含义 |
|---|---|---|
| 0 | OK | 成功/已释放 |
| 1 | RESIDENT | 外部引用已关闭，映像因引用/地址固定仍驻留 |
| -1..-4 | FORMAT/RANGE/SYMBOL/VERSION | 格式、范围、符号或版本拒绝 |
| -5 | NOT_FOUND | 文件不存在或调用者不能读取 |
| -6 | MEMORY | 实际分配失败 |
| -7 | CYCLE | 依赖环 |
| -8 | INIT | 初始化失败 |
| -9 | HANDLE | 非本人上下文句柄或没有外部引用 |
| -10 | BUSY | 装载/清理回调期间重入 |
| -11 | IO | 文件快照读取或平台保护失败 |

`ScRuntimeQuery` 返回版本 1 的模块数、逻辑映像/元数据字节、固定模块数、成功装载/复用/重定位累计数。逻辑字节不冒充实际 PF 页；物理页及页表/分配器开销由客体独立测量。计数采用 32 位，与当前上下文地址空间合同一致；累计次数回绕不作为安全决策。
