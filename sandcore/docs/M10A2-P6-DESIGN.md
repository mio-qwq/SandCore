# M10a2 主要组件重制设计

2026-10-16。此页保存后续实现设计，不是组件源码、构建或运行通过的声明。完整范围仍以根 M10a2RULE.MD 和 COMPONENT-AUDIT 为准。P5 尚在整合验收；先完善它，再实际接线主要应用。

## 公共约定

新应用只经公开 SC32API、SCCLIB、SCLIB、SCUI、SCSHELL 使用系统对象。应用可以有私有构造辅助函数，不复制控件、菜单、剪贴板、文件事务或动态装载器的算法。颜色取 GFX/主题命名角色，文字以凤凰字体的真实度量布局；Classic/Aurora 共用模型、事件和控制树。

窗口从菜单/工具栏、可调内容区、状态栏构成。最小尺寸和高DPI先分配实际可用空间，再处理 flex 收缩、滚动及面板切换；不能覆盖控件，也不把正文或图像的原生数据尺寸随窗口缩小。所有布局描述显式初始化合法 span。图标绘制传实际 ENABLED 状态；桌面文字使用既有阴影角色。

长操作按有预算的步骤推进，继续响应输入。隐藏只停止生成GUI帧，编译、搜索、文件传输、认证、音频保持工作。失败、取消、OOM和迟到消息不能替换活动作品或把旧输出冒充新结果。所有任务、窗口、请求、文件和模块使用真实ID/代数，不读取旧CPUINFO八槽作为动态PID数组。

缺名判断使用现代 FILE/DIRECTORY 的明确错误。旧 PathStat/Metadata 的粗 FAILED 不能直接解释成 NOT_FOUND；已有对象绝不因一次查询失败而覆盖或截断。

## Studio 2 与实际工程构建

主区域为工程树、文档页签和编辑视图，下方为可调输出/诊断区域；面板可停靠、浮动或恢复布局。每个文档分别持有 Document、真实文件路径、保存代数、视口、选区及撤销历史。语法高亮只更新改变的行及受词法状态影响的后续行；查找/替换、Undo/Redo、保存失败与关闭确认复用SCUI文档行为。

工程记录源文件、包含目录、对象、依赖库、目标类型、输出与构建配置。**不能用生成一个包含所有.c的聚合文件冒充多源工程编译和链接。** 需先审阅原生后端，再正式定义独立可重定位对象格式及链接入口，分别生成各源对象、解决跨对象符号/重定位，最后输出动态SCX或SCL。头、格式规范、源和构建规则同批完成。

当前实际G1为242638B、load242602B；旧SCX load预算262108B，余量19506B。链接器不能靠扩大旧容器上限塞进现有编译器。优先把对象输出作为小的前端扩展，独立原生CLI链接器承担布局、符号、诊断与SCX/SCL封装；最终分工依据真实构建体积确定。SCL现有段权限、初始化/终结、显式导入导出与版本检查继续保留。

构建使用真实受管任务与stdout/stderr管道。诊断包含本次源文件/位置与构建代数，可导航到对应文档；取消和退出真实结束子任务、关闭流并等待回收。只有本次源版本、本次配置和本次输出真实成功才启用Run/Debug/Publish；修改源码后不能继续把旧成功状态用于发布。GUI集成与独立sccc/汇编器/nano/scdbg入口共同保留。

## Debug 2

暂停现场包括反汇编、寄存器、内存、栈；模块及断点各有动态列表，状态栏说明真实运行/暂停/异常/退出。分割布局可调整，多面板在同一暂停代数同步发布；目标运行后不得把旧快照显示为当前现场。不能读取的字节明确显示不可读，未知指令保留真实字节的db回退。

先公开大写的typed调试头和对象合同，再移植既有真实TF/INT3能力。目标必须是有权调试的真实进程/代数；普通root不因此得到硬件SYSTEM或Ring0调试权限。继续、暂停、单步、断点增删、内存读取均由内核重新核验；GUI不能借其它用户/会话或猜PID。

动态模块视图需要正式版本化快照，包含实际映射范围、权限、装载代数及可追溯的库身份/符号。不能扫描目标私有SCLDR结构，或把主程序静态.map当成运行期SCL模块信息。符号名称只作显示/导航，不能授予内存读写权限；断点撤销、模块释放、异常和目标退出的生命周期共同接线。

## SDK 与验收接续

公开SDK包含真正公共头、库、ABI/错误/版本文档、检查工具、对象/工程工具和示例。私有WIRE、内核头和库实现不进入普通INC。独立复杂示例应在普通客体中完成多文件编译、第三方SCL链接、菜单/工具栏/树表/文件对话框/剪贴板和真实运行，不要求修改内核或复制系统应用源码。

每组件只做与其实际新增风险相符的代表工作流，复用已有SCUI/ABI/Unicode等未变证据。最终仍需真实键鼠/窗口/文件、Classic/Aurora、布局/隐藏、权限/兼容、性能和回收结果；没有新的证据不宣布组件或整版完成。
