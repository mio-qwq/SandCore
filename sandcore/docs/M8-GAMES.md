### 2.1 时间、战斗与身体

固定4个PIT tick为仿真步，100Hz计时；一昼夜60000tick，即客体10分钟。
天空、太阳方向、表面明暗随时间变化；夜间火把/营火/已激活信标照亮附近表面，
局部光检查实体遮挡。玻璃/水反射、透射和表面AO来自实际世界，不从宿主贴一帧图。

远征夜间最多六只夜影，以玩家附近真实地面生成、沿地形接近。
营地、已修复遗迹、火把与营火附近驱散夜影。攻击距离/朝向与实体墙阻挡都检查，
被击中有100tick间隔。玩家工具决定攻击伤害；击败奖励晶体1，库存满则保留
敌人/奖励，不先删敌人再丢物品。夜影真实球体求交并比较体素距离，不隔墙显示。
夜影是轻量地形追踪，尚无全局寻路、复杂动画骨骼或多人能力。

生命0后营地救援、保留物品并增加救援次数。营地/安全点恢复生命，草药即时恢复。
V持续冲刺消耗体力，停止后恢复；水中Space上浮，眼睛在水中消耗氧气，耗尽后
定时间隔伤害。眼高400、半径48使用Q8，水平分轴及竖直8单位小步碰撞避免穿墙。
Space在落地时跳跃。R回营需静止2.5秒，移动、受伤或夜间不安全会打断；成功冷却30秒。

### 2.2 输入与菜单

默认现代世界从菜单进入。Resume开始捕获鼠标，原始PS/2 dx/dy控制视角，
到达屏幕边缘仍能转动；左键采集/攻击，右键建造/修复。Esc立即释放并打开菜单。
暂停菜单逐页列出制作、背包、手册与地图；捕获中的HUD不抢视角点击，玩家
释放后仍可全程鼠标进入这些界面，无须记住四个快捷键。
失焦/最小化/异常/关闭同样释放；应用不能抢捕获别人的窗口。
QEMU宿主是否把物理光标约束在客体窗口由QEMU自身负责，客体不改宿主桌面设置。
legacy保留中键拖视角，不自动捕获；松开中键、失焦或离开视口清理拖动基点。

| 输入 | 功能 |

| WASD / Space / V | 移动 / 跳跃或上浮 / 冲刺 |
| 鼠标 / 左右键 | 捕获视角 / 采集战斗 / 建造修复 |
| 方向键 / Q E | 保留兼容视角 / 采集 / 建造 |
| 1–9 / 背包鼠标 | 快捷栏 / 替换当前栏材料 |

小客户区每页仅画得下的行，配方/库存/手册/菜单均有Prev/Next；不用只靠键盘
访问最后一项。制作页独立保留一行材料数量，窄窗也完整显示选中配方的消耗；
键盘选择与鼠标分页共用可见行数。独立页脚报告缺料、库存满、升级顺序及保存失败，
不让失败事务在模态界面里无反馈。关闭面板的同一鼠标沿不能再次挖世界。模式切换和退出发现未保存
状态时提供保存/丢弃选择；保存失败保持原世界，不继续离开。新世界另外确认，
只重置内存中的世界，原磁盘文件等玩家明确Save才替换。
逻辑客户区高度小于240时，HP/昼夜放在标题栏，底部只留快捷栏与四个工具入口；
不叠完整状态面板覆盖第一人称视口。低于260×160才暂停并提供Enlarge，状态保留。

## 3. DUNE RUN：三路线与三站赛事

| 路线 | 每圈单位 | 特征 |
|---|---|---|
| Dune Circuit | 60000 | 沙漠长弯、石/木站台、细沙与稀疏树景 |
| Coastal Run | 78000 | 连续S弯、右侧海面、沿海道路/灯塔 |
| Highland Pass | 96000 | 高频紧弯、远山、草坡和三层实体松树 |

每路线有不同周期曲率，物理和道路绘制共用曲率函数，圈接缝连续。
球/盒/三角形斜车舱与场景真实射线求交，道路、车体、影子、道路景观共用
相机眼高720与动态焦距；近车尺寸随真实z增长，不用固定屏幕图标代表远近。
景观/细节锚定里程，重复绘制同一时刻不会随机换物件。

计时赛三圈，没有交通干扰；锦标赛固定三路线各三圈，同一五名对手参与。
自由跑没有终点，离开极远范围的车重新成为前方交通；legacy保持12000单位原圈长
与原HOME/RACE/RECORD 4B记录。旧SCX独立在LEGACY，不依赖新记录才能启动。
新比赛3秒倒计时；每步4tick，倒计时不计入比赛用时，暂停不走时。

五对手各有累计里程、速度、车道、完成tick。弯道减速、邻近车道避让；碰撞看
前后相对位置防高速穿车，60tick接触冷却。名次来自真实状态，玩家减速时对手继续
前进。不是脚本指定胜利、固定屏幕对手或每帧刷新一次的预设名次。

| 控制/策略 | 行为 |
|---|---|
| 方向/WASD / 鼠标踏板 | 油门、刹车与转向 |
| N / 鼠标Boost | 消耗氮气；良好车况时提高极速 |
| Space / 鼠标Drift | 提高转向能力并减轻弯道外推；补充氮气 |
| 车损 | 碰撞显著损伤、离路缓慢损伤；限制极速 |
| 起点右肩维修区 | 前2400单位、靠右、速度低于32时恢复耐久/氮气 |
| M / Esc / 鼠标Menu | 暂停；菜单编辑为候选，Back不改变正在进行的路线 |
| R / New | 仅未完赛时重启本场；已结算后禁重复重开同一站 |
| Enter / 结果鼠标 | 下一站或重赛 |

Touring/Sport/Expert控制对手速度；菜单按路线、赛事、难度三页鼠标可选。
低于240逻辑像素高时，状态合成一行，场景视口明确扣除底部76单位操作区；
道路/车体共用缩短视口的焦距，避免近车被踏板完全遮住，HUD报告真实场景像素尺寸。
锦标赛每场按名次1..6分配6..1分给六名车手，最后按三场累计积分列出排名，
同分按固定车手顺序排出稳定名次，显示排序不改各车手的积分身份槽。
不能用最后一场名次冒充总冠军。140像素高结果卡以Table轮换摘要与六车手；
更高卡片在摘要下分页列出积分，保存提示和操作按钮独立留出空间。已结算后的
R不会再次累计同站积分；Next event保留积分推进，Replay重置整个系列。
中途退出/暂停不登记
完成成绩；完成三圈后保存，失败提示并提供S重试。
