# M10a1 设计与已批准合同

> 2026-10-06：用户批准开工；基线提交24797e0。本文是实施目标，不是完成或验证证据。
> 当前开发分支codex/m10a1；先写齐全部实现/资源/规范，再统一构建和实际客体验证。

## 1. 范围与顺序

最高优先级：取消固定任务数量门槛，以动态对象、就绪/等待队列、可靠生命周期和按真实资源失败替代NTASK=32。凭据、环境、调试、SIMD、图像等任务旁表同步；作业/端点/管道/会话/窗口动态增长，不能成为新的总任务门槛。旧8/32行ABI缓冲严格保留，新增分页接口与新版工具读取全部对象。

顺序：动态任务/调度 → 会话隔离与隐藏绘制 → 主内核/签名扩展 → TTF/扩盘 → e1000/IPv4/socket/网络CLI → 统一验证、修复和验收。难点不得未经用户许可削减或封存。

M10a1为M10a开发版本，可commit，无Release。保持当前M9修复、M9正式产物与M8冻结成果。IPv6、浏览器、SMP、GPU、输入法不扩入本轮；M10完成时才评估冻结底座。

## 2. 主内核与启动合同

BIOS → 最小loader → /SYS/CORE/CORE.SKM主内核 → 已验签按编号排序的扩展 → 用户服务/桌面。

loader仅承担启动准备、必要磁盘读取/SandFS只读定位、格式与装载边界检查、启动信息、早期串口诊断和恢复。调度/内存/中断/系统调用、完整文件系统、权限、调试管理、窗口/音频/字体/网络等进入主内核。新增带版本/映像类型的装载格式，保留SKM1与旧服务表前缀。

原CORE壁纸模块转为独立扩展，历史字节和源码保留。恢复主内核放独立恢复目录，避免当扩展执行；装载失败可恢复，进入Ring0后的异常按诊断合同处理，重启可选择恢复。

## 3. 扩展签名与用户独占私钥

签名排序针对CORE目录除CORE.SKM外的扩展类型SKM；主内核另走装载合同。采用Ed25519。格式/长度/版本/CPU与ABI/重定位全部检查；签名覆盖内部编号、版本、入口、BSS布局、重定位和载荷。仅通过的模块参与唯一编号检查和升序执行；重复编号全部冲突模块拒绝，无签名/坏签名/坏格式不运行并记录原因。

每次启动一次初始化，可留下常驻回调/驱动/服务，到重启释放，不热卸载/热重载。真实Ring0代码非沙盒。

私钥仅用户生成、保存、使用；代理不生成/读取/保存/代用。仓库与客体只含用户认可公钥。代理提供可审阅待签源码/产物、编号/用途/摘要、离线签署说明与验证工具；用户在自己控制的环境签署并返回结果。没有用户公钥/签名，正向装载标待验，不引入替代信任入口。

更新通过受控外部SYSTEM管理链路，普通/root及普通SYSTEM服务不因此得到零环管理资格。现有MOD、一次性执行及管理串口边界保留。

## 4. 会话与图形

会话与UID分开，进程创建绑定身份/会话/代数；切桌面不改旧进程身份。窗口层级、焦点、任务栏、桌面配置、输入与错误弹窗按会话隔离，截图保留权限边界。SYSTEM管理窗口默认不进入普通桌面，经明确外部管理操作才展示/切换。

隐藏会话不合成、不绘制；内置GUI收到实际可见性变化后停止生成隐藏画面、栅格化与帧提交，切回完整重画。不以失焦代替不可见，不暂停整个会话；网络/音频/CLI继续。历史程序私有计算成本单列，不能只跳最终合成称全部停画。切换清理键鼠边沿、拖动/相对鼠标状态，注销/退出/槽复用完整回收。保持mio原桌面与用户修改，明确当前会话身份，配色走GFX槽位。

## 5. 字体与存储

ZIP构建时仅解出原样VonwaonBitmap-12px.ttf/16px.ttf；客体直接TTF整数/定点解析与栅格化，完整cmap字符映射，字宽/基线/轮廓、原生字号及所需缩放。旧ASCII/GLYPH16/文字ABI不改，新能力新接口或版本结构；同源恢复小字库保留。

缓存按字体版本/字形/尺寸区分，明确失效与归属；Notes光标/选区/滚动与源码中文注释、全系统文件名/终端同步。统计字形与实际字符覆盖，列源码仍缺字符；坏文件不可激活半张字库。原字体包、许可证和来源记录保留。

开发数据盘256MiB，参数化容量；创建新副本，保留原盘内容/UID/GID/rw/用户修改。同步ATA/FS边界、打包迁移和桌面镜像编辑器、容量UI；旧8/64MiB盘兼容。空闲分配/统计减少逐扇区重复扫描，提交/撤销失效明确；编辑器测峰值内存/耗时。第三方完整归档后核对2048目录项，若不足正确迁移，不删资源腾位置。

## 6. 网络与第三方

Windows QEMU、单vCPU/i386、e1000；PCI/BAR/DMA收发环、中断、链路、回绕、错误/复位/回收。IPv4主机协议：以太网/ARP/IP/ICMP/UDP/TCP、路由/MTU/分片重组/错误报文、TCP完整连接/关闭/重传/乱序/流量拥塞控制、静态地址/DHCP客户端/DNS。

lwIP固定来源版本，freestanding整数适配，不引标准C运行库/内核浮点。协议事件在受控上下文处理，IRQ不重入，批次/队列/定时器有预算。新增socket/就绪等待/管理接口检查地址、长度、身份、代数与退出回收；SCAPI旧功能号/寄存器/缓冲只增不改。普通用户联网，网络配置检查管理权限。

SYS最高权限仍仅外部物理串口模型；NAT网关/转发/宿主QMP/HMP不得成为自连或注入管理串口通路。无网卡/断链返回明确能力状态。

源码固定在third_party，完整版权/许可证/免责/作者/专利等原文、内部依赖、摘要/用途/适配同步THIRD-PARTY；客体SYS/LICENSE归档源码和声明。仅MIT/BSD等符合工作区许可约束的实现，逐文件审查，宿主工具另列。

## 8. 统一验收

全部实现收齐后统一构建、客体编译、Windows双来源数据盘无头QEMU。此开工授权涵盖后续验证，不另加阶段审批；缺签名输入时继续其它独立验证，缺项诚实标待验。

启动/签名：新核心冷启动、类型/格式/坏映像/恢复；用户有效签名、目录逆序仍编号顺序、冲突/编号与载荷篡改/坏ABI/重定位、初始化及常驻生命周期。
