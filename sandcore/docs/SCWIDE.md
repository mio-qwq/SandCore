# SCWIDE：双32位整数源库

> mio，2026-10-04。库已由历史M7与新收敛G2真实编译、运行，完整数值
> 和调用约定通过。精确三角形接线及实际游戏画面/帧率另验。

`SCWIDE.H`先声明，`SCWIDE.inc`实现。仅使用32位整数、基本i386
整数乘除/进位，不要求long long、FPU、SIMD、libc或内核新调用。
普通三环源码include实现即可；不创建窗口，不申请内存，不拥有
场景或全局内核状态。它是通用整数库，非赛车私有补丁。

`ScwInt`固定8字节：偏移0为u32 low，偏移4为int high；合并为二补码
64位。`scw_cmp_signed`按有符号解释，`scw_cmp_unsigned`按无符号
解释。所有指针由调用者提供，必须指向存活的完整对象；允许输出
等于任一输入对象，不承诺空指针。除下述dot3v明确的4B对齐部分
重叠合同外，其余对象接口不承诺部分字节重叠。

| 入口 | 合同 |
|---|---|
| `scw_mul32(out,a,b)` | 完整有符号i32×i32乘积，永远可精确表示 |
| `scw_add/sub/neg` | 模2^64运算，包括进位/借位与INT64_MIN |
| `scw_dot3(out,ax,ay,az,bx,by,bz)` | 三个完整有符号乘积的模2^64累加 |
| `scw_dot3v(out,a,b)` | 两个连续3×i32向量；各12B输入、8B输出、4B对齐，允许输出全部或部分覆盖输入，数值与dot3完全一致 |
| `scw_ratio16(out,N,D)` | 向零截断N×65536/D，分子幅值≤2^48−1 |

比值分母可为任意非零有符号64位整数，包括INT64_MIN。
成功返回0；结果超过±2147483647则饱和并返回1。分子超界返回−1，
分母为零返回−2；错误写0，除零优先。不能把任意64位分子的左移
回绕当成有效结果。调用者须证明几何/统计数据符合分子范围。

GCC或`__SCCC_WIDE__`使用IMUL的EDX:EAX完整乘积、ADD低字与ADC
高字。含汇编函数按cdecl保存EBX/ESI/EDI。历史编译器没有能力宏，
走16位肢体纯C乘法；每个中间量以u32计算并证明不溢出。64/32
比值先检查高字小于除数，再用已有DIV；宽除数以最高位对齐后
最多32次试减。只有确实需要宽除数时进入循环。

dot3v的非重叠快路在一次汇编中从输入直接加载三个分量，执行
完整EDX:EAX有符号乘积及低字ADD/高字ADC；减少六个实参压栈
以及三个乘积函数的重复调用，不截掉高字、不申请缓存。首先用
u32地址双向差值检查输出8B是否与任一输入12B相交；不能用可能
回绕的末端地址来检查。相交时先读取全部六个标量，再调用原
dot3，避免第一次写输出破坏后续输入。旧M7一直使用相同标量
路径。a/b可相互重叠，返回后不保留任何指针。有效对象须完整
位于可访问地址区间，不能跨地址空间末端。

源级能力宏与库不是SCAPI.H内核ABI，原调用号/布局/寄存器含义
不变。旧SCX继续运行，旧编译器也能编译纯C路径。系统安装源码
位于SYS/SRC，公共头另在SYS/INC，Makefile按现有源扩展规则接入。
