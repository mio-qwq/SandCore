# M9 自写 nano（源码，未验证）

> 当前验证范围已更新，见末尾“2026-10-05 M9最终验证记录”及[M9验收报告](M9-ACCEPTANCE.md)。早期未验证/待验标记保留阶段背景。

用户2026-10-05明确不要vi，选nano。实现是SandCore自己的编辑器，未复制GNU
nano源码；独立入口`user/m9/nano.c`，私有核心SCNANO.H/inc。无窗口，不直接
访问UART，复用本人已有终端；宿主先`:raw`逐键输入，Ctrl-]回宿主菜单。

`nano [-v] [+LINE] [FILE]`：文件最多4MiB/131072行，拒绝含NUL的文件，
保留CRLF、末行无LF及原始UTF-8/无效高位字节。界面把文件控制字节可视化，
不会把文件里的ESC发给外部终端。光标用可见`|`标记，按UTF-8标量移动和删除，
宽字按两列、Tab按8列导航。竖直导航记住目标列，长行横向查看。

| 操作 | 外部终端 | 客体PS/2功能键 |
|---|---|---|
| 保存/另存 | Ctrl-O，Enter确认路径 | F2 |
| 退出 | Ctrl-X；未保存时y/n，Esc取消 | F10 |
| 字面搜索 | Ctrl-W | F5 |
| 剪切当前行/粘贴 | Ctrl-K / Ctrl-U | F6 / F7 |
| 跳到行/帮助 | Ctrl-T / Ctrl-G | F9 / F1或F8 |
| 撤销/重做 | Alt-U / Alt-E | 可依次Esc、U/E |
| 行首/行尾/翻页 | Ctrl-A/E或ANSI Home/End/Page | 方向键；其它导航走ANSI |
| 插入文件/刷新 | Ctrl-R / Ctrl-L | 外部终端快捷键 |

输入路径/搜索提示框支持ASCII输入，Ctrl-U清空、退格、Enter确认、Esc取消。
当前没有正则搜索、选区、多缓冲、语法着色或完整GNU nano配置语义，不声称
与GNU nano全选项等价。Ctrl-C沿Shell前景取消链路结束任务，非保存退出。

正文采用gap缓冲，连续键入不搬整个文件；行索引二分定位，修改后更新受影响
的索引。撤销/重做最多32条、8MiB正文历史，分配失败在改正文前返回错误。
保存一次写COW事务，只有commit成功才清修改标记；失败保留旧文件与缓冲。
当前保存不提供文件锁或外部编辑冲突对话，尚需统一验证权限/资源生命周期。

终端输出按真实网格截行，最小16×5。串口暂定80×24；窗口终端历史仅16KiB，
编辑器据最坏UTF-8帧字节预算限制页行数，保证一页不被历史回收截掉。静止时
不重绘，输入/尺寸变动才提交，保持真实文件完整、不裁剪保存内容。
