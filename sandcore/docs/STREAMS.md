# M9 字节流与命令行作业

> 当前是实现阶段源码合同，尚未构建或运行；验收状态见 M9-IMPLEMENTATION.md。

每个进程有16个描述符，0/1/2为标准输入/输出/错误。描述符引用内核端点，
端点保存文件对象代数、偏移、方向和资源归属。创建子进程通常继承同身份的
0/1/2；SPAWN2可显式选父进程已有描述符，不能传内核端点编号或任意PID。
认证切换仅能共享终端、管道和空设备，另一身份打开的文件/写事务不继承。

读写最多65536字节，均非阻塞：正数为实际传输，0为EOF，-6为暂时无数据/空间，
-7为管道无读者，-8为对象已改变。调用者遇到-6让出再试，不能空转。
共享描述符共享文件偏移；文件修改、改权限、重命名、同名重建使旧代数失效。
每次文件读取还按调用者真实身份检查r，不缓存“永久绕过”的打开授权。

替换文件先保留调用者指定最大容量；顺序追加，close(fd,1)提交，close(fd,0)
关闭引用，最后一个引用关闭则取消未提交事务。提交仅原owner可发起。Shell保留
输出事务，子程序只能写正文，全部任务结束后由Shell提交。写入容量不足不发布
截断产物。默认重定向容量1MiB，可export REDIRECT_LIMIT调整；此值是真实磁盘
保留空间而非RAM预分配。追加先流式复制旧内容到新事务，随后追加新内容。

管道正文4096字节，计数记录所有读/写描述符；最后一个writer关闭后读到EOF，
最后一个reader关闭后writer得到-7。父Shell在启动所有管道阶段后关闭其管道
引用，避免“父进程还握着writer”导致永久等EOF。最多16条管道/128个端点。
常驻表一次从普通物理页分配，不挤占低端BSS；正文读写不分配内存。

SPAWN2返回内核作业票据，绑定父/子进程代数。WAIT2的32字节快照保留结果，
子PID复用不覆盖退出码；领取完成结果后释放票据。最多64条记录，耗尽返回-6。
进程退出取消其受管作业并关闭引用；GUI历史EXEC保持原行为。KILL2只接受本人
或同UID目标，root可管理普通身份，SYSTEM目标另要求外部串口SYSTEM资格。

旧GETARGS/CLI/PUTS/STATUS布局保留。新ARGUMENTS2提供1024字节完整参数视图；
旧128字节任务结构参数保留前127字节。新PROCESSINFO2为520个u32，头8字、32行
每行16字，包含PID/状态/代数/UID/GID/名字；旧CPUINFO仍恰好写64字。

环境使用带引用计数的不可变快照，父子同身份共享；修改时写时复制，退出释放。
旧全局ENV配置仍由管理身份保存；ENVSET只改本进程快照，孩子取创建时快照。
USER/HOME/PWD由真实身份和cwd生成，不能用环境修改身份。最多16个普通变量，
每值255字节；Shell另保存48个局部变量，export才传给子程序。

## 内存脚本与终端能力

STREAMMEMORY复制最多32KiB不可变正文，用于here-document/脚本输入。
最后引用关闭回收页；共享引用共享读游标，认证切换不带走旧身份的快照。
SPAWNBUFFER2通过正常SH.SCX装载创建同身份可等待作业，fd3单独接脚本，
0/1/2仍按调用者指定的标准流；不借临时磁盘文件或预写有限管道传递整份代码。

STREAMOPEN模式8复制调用者已有的窗口/管理串口端点，不打开设备节点或
客体UART。stdin是管道时分页/编辑工具可用此能力读键，正文仍从原管道来。
TERMINALINFO2返回独立32B快照，当前窗口网格随尺寸变化，串口暂定80×24。
TERMINALCLEAR仅支持可写TTY/SERIAL；串口控制序列全排入或完全不排入，
不能在部分写后重试同一前缀。所有新增调用完整布局见SYSCALL.md。

窗口终端新字节流允许UTF-8标量跨write调用，端点最多暂存四字节，完整
标量才交给WM校验/绘制。每轮至多处理256输入字节；NUL/坏序列明确失败。
旧PUTS输入校验与返回合同保留，文件/管道/串口始终按字节传输。
