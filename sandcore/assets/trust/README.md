# M10a1 用户公开信任根

M10-OWNER-ED25519.PUB是用户提供的32B原始Ed25519公钥，SHA256为
fc0f26d1b2f3cfea86ca19f3d5d37acd2fea932f683307887ace3bda7200e4f7。
M10-PUBLIC-RESULTS.json只记录公钥和编号100壁纸签名产物的公开摘要。
本目录没有私钥、密码或私钥路径，代理未生成密钥或代签。

M10a1正常构建默认固化此键；显式M10_PUBLIC_KEY可选择另一个用户
公钥，显式空值构建无键主核并拒绝全部CORE扩展。更换键不替用户
签署旧模块。编号10/20/30及故意错误格式只在独立受控验收盘使用。
正式随盘扩展目录为modules/signed，当前仅WALL100.SKM。

修订：2026-10-07，归档用户公开结果并接可重复构建；私钥仅用户持有。
