早期独立启动的75/143PIT受后台初始化顺序影响，不作可靠前后比较。comparison01是检查程序main签名错误；comparison02测到旧库后，管理传输正确拒绝受保护SYS/LIB替换；没有绕过保护。comparison03分项及退出账通过，但随后桌面流程因旧检查把隐藏准备也算进15秒首帧期限而整体FAIL，原报告保留，不能改称整体PASS。
