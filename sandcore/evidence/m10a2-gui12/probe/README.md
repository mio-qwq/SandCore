# 新UP入口的定向输入检查（源码，尚未编译/运行）

`DROPUP.C`只依赖公开SDK和动态库。必须在真实UID1000/realm0普通桌面运行，由真实PS/2按住源按钮并拖到右侧目标后松开。没有生成或注入ScMessage，不写客体内存，也不做文件操作。

同一次手势检查无UP、错误序号、错误落点、非零保留字段、真实UP、重复消费及票据/capture释放。负返回时独立比较整个输出与原哨兵，正向核实际源身份、目标窗口和同SID。原生SCUI负责两窗、布局、文字、主题与输入；原始Drop调用只在应用收到真实事件的回调中执行。

这是新内核授权入口的必要边界检查，不替代Files与桌面的实际拖放确认、COPY/MOVE、取消或最终owner账。当前只准备源码，正式清单仍需从真实SCO导入表取得；不能把本README当PASS。
