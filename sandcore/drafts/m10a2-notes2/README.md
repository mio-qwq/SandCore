# Notes 2：共享文档与可靠保存

主代理所有，2026-10-16。这里只写新的原生用户态组件；旧 `user/note.c`、SCX 和用户作品保持。公共依赖 SC32API v5、SCCLIB、SCLIB、SCUI v2，不复制 NUI/编辑控件，不直接使用 syscall。

界面为标准菜单、短工具栏、占满客户区的共享 Edit、可收起的查找/替换栏和状态栏。Classic/Aurora 共用控件、布局和命令；尺寸采用逻辑单位，文字采用同源字体。默认打开 `/HOME/notes.txt`，缺失时保留有路径的空文档；保留 F2 保存、F3 重载、Escape 关闭，并新增标准 Ctrl 快捷键。

打开使用稳定只读 lease、分块读入候选，完整 UTF-8 验证/文档构造成功后才替换。加载中原文仍可编辑；原文修订变化时拒绝迟到的加载结果。保存先取得不可变文档快照，写入目的目录中的 mode3 私有候选；flush 后按观察到的目标 revision 条件发布，只有 durable ACK 才更改当前路径/保存状态。保存时产生的新编辑不被标记已保存；任何失败保留内存文档。取消、退出和资源回收遵守真实 lease 终态，不能把取消到达过晚的已提交结果说成回滚。

实现包括共享选区/剪贴板、Undo/Redo、查找/向前向后、大小写选项、替换/全部替换、打开/另存/重载/未保存确认和真实错误提示。文档/文件以实际内存和文件系统能力为界，不保留旧64KiB固定正文数组；路径仍按现有63B rootless限制，不声称支持空格。
