## 已有宿主证据

`build/m10a2-files2-agent-host/report.json` 与 `host.log` 记录此次实际输入摘要、命令和输出。

- WSL GCC i386，`-Wall -Wextra -Werror`，freestanding，无 SSE/MMX/浮点或 libc 静态实现复制。
- `tools/mkdscx.py` 验证真正动态容器：5个库、168个精确导入、746个动态重定位。
- `FILES2.SCX`：74,980 B；SHA256 `297018c47480d8470341384cd2157c9b95dc065c338e01ac93616f9a6b21c4b0`。
- `MODEL_HOST.C` 调用同一实际增量排序/过滤/rank 步进器，独立 libc qsort 对照；0/1/513/10,007行、7字段、升降序、ASCII/中文过滤和空结果。64位宿主 ASan+UBSan：56 cases / 249,241 assertions 通过，无 UI 或文件 API 执行。

宿主用的是宿主 libc 的独立期望与 sanitizer；正式 i386 SCX 导入 SCCLIB。这项模型检查不证明目录分页、Ring3 调用、剪贴板、worker 提交、画质、帧率或整机性能。
