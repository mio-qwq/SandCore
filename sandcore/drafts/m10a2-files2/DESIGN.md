# Files 2 实现设计

2026-10-16。目标是实际 Ring3 文件管理器；本目录在整合前不改默认 FILES.SCX，原 `user/files.c` 和历史字节保留。这里只使用公开 SC32API / SCCLIB / SCLIB / SCUI / SCSHELL。

## 画面与交互

Classic/Aurora 共用 SCUI 控件和主题角色。窗口由菜单、紧凑工具栏、可编辑地址栏、过滤/子树搜索栏、左右可调分割区、详情表格和状态栏组成。左侧目录树按展开取批，右侧表格提供名称、类型、字节、UID/GID、权限、修订和完整路径。真实文件系统没有时间戳，不显示虚构日期。列宽由标准 TableView 调整，所有行仅按可见区请求文字与关联图标。

菜单/工具栏共享命令；地址回车导航，Alt+左右为历史，Backspace/Alt+上为上级，F5 刷新，Ctrl+L/F 定位地址/过滤，Ctrl+C/X/V 使用系统 FILES 剪贴板，F2 重命名，Delete 删除。保留原 Files 的 SCX 启动、图片交 Lens、源代码/明确文本交 Studio、SCX 调试入口；未知二进制要求选择应用。标准文件/目录对话框、属性和上下文菜单均来自共享库。

## 数据、身份与异步

- 每项拥有完整绝对路径、kind、实际 revision 和稳定应用 item ID。显示省略、排序位置、同名搜索结果均不作为操作身份。路径候选允许超过正式长度；随后完整拒绝，绝不截断成其它目标。当前 SandFS 拒绝空格，不声称支持空格路径。
- 目录用现代 Directory 分页读取。导航/刷新/子树搜索先构造候选，失败、取消、STALE 或 OOM 保留当前目录、选择和历史；完整成功后原子发布。不存在仅由精确 ScPathQuery 的 NOT_FOUND 判断。
- 行数与树/搜索队列动态增长，没有 512 项截断。过滤构造索引，排序采用分步稳定归并和独立 rank；鼠标移动不读取目录、不全量排序。
- 目录树未展开节点只有占位子项；真正 CHILD_AT 请求才排队读取，不因绘制展开箭头而扫描整棵树。每次只推进一个有预算的目录批次，完成后一次发布该节点子项。
- 目录读取、排序、搜索和书签持久化每轮只做有限工作；纯 GUI 隐藏时不生成帧。实际后台事务继续运行。无工作时 BrokerWait 等输入、STREAM、JOB、可见性和 SCUI 截止时间，非无限轮询。

## 文件操作和恢复

ShellMenu 自有文件项快照负责创建目录、重命名、删除、冲突决策和进度；独立菜单工作对象在弹层关闭后继续存活。复制/剪切/粘贴直接用 SCSHELL FILES 对象。真实跨窗口 Drop 由 SCUI 认证生命周期交 SCSHELL 建立 caller-owned worker；复制/移动选择不删除来源。对 completed/durable/source-retained/uncertain 逐项区分，只有 DONE + DURABLE 的结果报告成功；不确定时显示检查/恢复路径，不自动重发破坏性操作。

新空文件和书签配置使用公开文件租约：不可见候选、flush、条件 publish、Advance、durable 终态、Release、Close。书签保存先核现有目标 revision；冲突不覆盖磁盘配置。失败保留内存书签及明确未保存状态。所有确认取消均不改当前选择。

## 资源归属和整合边界

应用拥有 Context/根、providers/selections、当前与候选快照、树缓存、历史/书签、catalog 快照、菜单工作链、租约和 Drop 正文副本。Provider 只借本进程值，不取得内核结构。共享图标按类型/关联代数缓存；主题/显示/目录及 catalog 变动分别失效。退出先取消拖放/任务与租约，再销 UI 和数据，保留真实错误记录。

正式动态清单必须由实际 i386 object 的未定义符号生成并验证，SC32API 最低 ABI1.3 / version5，SCUI 最低 ABI1.1 / version2。宿主构建只证明语法、导入与容器；客体键鼠、权限、双窗拖放、隐藏/回收、Classic/Aurora 和真实磁盘行为由主代理定向验证。本目录不启动 QEMU，不宣布组件或整个 M10a2 完成。
