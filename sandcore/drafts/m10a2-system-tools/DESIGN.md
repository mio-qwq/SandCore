# Calculator 2 / Palette 2 / Monitor 2 设计

2026-10-16。三应用是真实 Ring3 SCUI/SC32API/SCCLIB/SCLIB/SCSHELL 动态应用；原 calc.c/palette.c/monitor.c、镜像与 Git 不改。公共控件承担输入、选择、表格、菜单、剪贴板和对话框；应用只拥有算式、调色板快照、采样和图表数据。画布只用于实际历史图和色样展示，不复制私有控件或 NUI。

## Calculator 2

保留有符号32位四则、键鼠、退格、清除、除零与溢出守卫；升级为带优先级、括号、嵌套一元符号、十六进制字面量和余数的表达式。十六进制同样表示有符号幅值，`-0x80000000`有效，正`0x80000000`越界；结果另列可复制的十进制及带符号十六进制。中间运算无浮点、long long 或有符号溢出。输入允许4096B，递归深度64，拒绝时保留全部输入并标出真实字节位置。标准 Document/TextBox 提供编辑/选区/撤销，历史表可恢复表达式，跨应用复制使用系统 TEXT 剪贴板。

菜单、表达式、结果、可调历史和6列键盘共享命令。数值错误不清除表达式、不复制旧成功答案。C键在十六进制数字中保留为数字，其余位置保留旧清除语义；AC按钮和菜单始终明确清除。

## Palette 2

实际调用 ScDisplayPalette 取得全部256槽，只读而不改DAC。TableView按可见行提供色样、槽号、GFX用途/登记状态、HEX、RGB与旧程序可达性；0是保留黑，1–104登记且旧版可达，105–255未分配。另一个视图列出 ScThemeQuery 的24个实际主题角色，明确原始DAC与主题颜色的独立来源。筛选、选择SpinBox、详情色样、RGB/HEX复制均为真实数值。色样只从实际快照创建ARGB图标，其它UI颜色一律主题角色，不新增裸色。

保留三种程序壁纸（0沙丘/1夜色/2暖沙）的持久化和图片优先提示。原公共SC32缺该入口，本目录单独提供 SC32WALL.H 与私有桥/内核只读query接线草稿：Set复用原0x18，Query用SYS300 selector0x006读本人真实会话view。缺视图明确NOT_FOUND；image-selected只表示配置路径，不冒充图片已经解码。主源ABI1.3/v5保持，新增导出待Root统一库v6整合。

## Monitor 2

ProcessPage按批次动态收集，复用当前/候选双缓冲；每行保存本页总样本、PID、generation、公开flags，匹配同一身份后才求CPU差分。完整成功才发布provider与索引，OOM/失败保留旧正文并明确标旧快照。可排序/过滤表格、属性、复制和确认终止使用真实PID+代数；操作前重新查询，权限始终由内核判定，PID0不可终止。没有进程内存字段时不编造RSS。

CPU来自真实PIT样本，graphics是kernel子集；100Hz是采样率，不是FPS。内存来自ScSystemMemory；卷只显示ScSystemStorage真实字段，不伪造旧接口未公开的ATA历史洞或分区。120点CPU/内存历史有各自有效位，失败点不连成零。冻结停止采样并保留画面；恢复清基点，冻结间隔不参与差分。可见时约1秒采样，隐藏时5秒后台采样并停止图表生成；切回立即请求新样本与重画。图表通过SCUI Class/Painter和既有命名角色绘制，按实际尺寸裁剪。纯空闲等待Broker/SCUI截止时间，不按鼠标移动重新枚举。
